模拟电路：从二极管到电源的"非理想"世界

数字电路骗自己"0 就是 0、1 就是 1"，模拟电路不许骗。 本关用 3 个 C 算盘 + 2 个 HTML 教具，把二极管、运放、电源这三件套的 非理想账本一笔一笔算出来、画出来：有限增益、带宽、压摆率、撞轨、 热耗、纹波、饱和——每个数字都是将来少烧的一块板子。

本 关 文 件 清 单

tutorial.md
课本（本关总纲）
为什么模拟是分水岭、学习目标逐条自检、12 条常见坑、5 道家庭作业、通关标准。
学习重点：先通读它，再碰代码；作业全在里面，别跳过。
01_diode_rectifier.c
C 算盘（编译：gcc -std=c17 -O2 -Wall -Wextra）
牛顿迭代解二极管方程求工作点；数值仿真半波 / 全波 / 桥式整流，量纹波、导通角、开机浪涌；稳压管限流电阻与功耗。
学习重点：滤波电容越大纹波越小、但峰值电流越大——同一件事的两面；开机浪涌看合闸相位，过零约十几倍、峰值合闸可达几十倍，这就是烧桥的原因。
02_opamp_lab.c
C 算盘（本关心脏）
内置非理想运放模型（有限 A_ol、GBW、SR、输出摆幅、Ib、Vos），对反相 / 同相 / 跟随 / 差分 / 仪表放大器五种拓扑一次算出实际增益、误差、−3dB 带宽、f_max(SR)、撞轨与失调折算误差。
学习重点：同一增益下电阻取 1k/10k 和 100k/1M 完全不是一回事；先算 f_cl = GBW / NG，工作频率接近它的一律重来。
03_power_supply.c
C 算盘（选型账本）
LDO 热账（Tj = Ta + P·θja、105℃ 降额线）与 Buck 全账（占空比、ΔI_L、峰值电流、损耗分解、频率扫描）；电感材料饱和曲线；输出电容容值/ESR/ESL 三笔账；LDO PSRR 与降额清单。
学习重点：12V→3.3V 500mA 用 LDO 时 Tj 算出来 500℃+ ——这不是选型问题，是着火问题，必须换 Buck。
opamp_animator.html
HTML 教具（双击即开，最重要）
选拓扑、拖 R1/R2/电源轨/GBW/压摆率/频率/幅度，SVG 实时画输入输出波形：撞轨顶部削平标红"削波"，压摆率不够画成三角标红"压摆率限制"，频率过高按 GBW 衰减增益。
学习重点：四个 preset（理想 / 撞轨 / 压摆率不足 / GBW 不足）逐个点，看右侧一句话诊断怎么变，直到你能提前猜中。
filter_bode.html
HTML 教具（双击即开）
一阶 RC 低通 / 二阶 Sallen-Key 低通（可调 Q）/ 一阶 RC 高通，拖 R、C、Q 即时重算对数轴幅频 + 相频，标出 −3dB 点与 Q=0.707 和 Q=2 的峰化差别。
学习重点：点"ADC 抗混叠"preset——1kHz 信号 10kSPS 采样，看截止频率该定多少、污染带里的频率各被压了多少 dB。

学 习 顺 序 建 议

  1. 通读 tutorial.md 第一到三节，明确学习目标。
    不知道要学成什么样就开跑，等于蒙眼走路。
  2. 编译运行 01_diode_rectifier.c，对照输出把整流三兄弟（半波/全波/桥式）的纹波、导通角、浪涌数字抄一遍。
    先把"非理想"的第一课——二极管压降不是常数——刻进脑子。
  3. 跑 02_opamp_lab.c，重点看"5 拓扑 × 4 组电阻"对比表和两个翻车案例。
    这是本关心脏：有限增益、GBW、SR 三本账全在这张表里。
  4. 双击打开 opamp_animator.html，把 02 算过的场景在动画里复现，再拖滑杆故意翻车。
    数字算完再看波形，"撞轨削平""正弦变三角"才真正长进眼睛里。
  5. 打开 filter_bode.html，玩 Q 峰化和 ADC 抗混叠 preset。
    滤波器是运放和 ADC 之间的桥梁，波特图必须是本能。
  6. 跑 03_power_supply.c，把 LDO 与 Buck 的选型账各算一遍，最后照降额清单过一遍自己手头的板子。
    电源是最后一个坑最多的环节，放最后是因为前面所有"非理想"思维在这里汇总。
  7. 回 tutorial.md 第六、七节，做作业、对通关标准。
    作业不动手 = 白学。每道题都要有算过的数字。

常 见 坑（节选，完整 12 条在 tutorial.md）

运放输出直接接大容性负载 → 自激。 输出"随手"并 100nF，等于往反馈环里塞极点，跟随器变振荡器。正确姿势：输出串 10~100Ω 隔离电阻。
压摆率当带宽用。 f_3dB 够不代表正弦不失真：满幅 V_peak 需要 SR ≥ 2π·f·V_peak。超过 f_max 输出变三角波，示波器上"看着还有波形"，谐波已经烂透。
LDO 只算 P=(Vin−Vout)·I，不算封装热阻。 470mW 听着小，SOT-223 的 θja≈105℃/W 就是 +49℃。算热必须走 Tj = Ta + P·θja，θja 还要按实际铺铜打折。
DCDC 电感按平均电流选饱和电流。 1A 输出 + 40% 纹波，峰值就是 1.2A。规则：I_sat ≥ 1.3 × 最坏峰值电流，否则磁芯饱和、纹波暴涨、EMI 爆炸。
示波器探头 ×1 档把被测电路带宽拖死。 ×1 档 100~150pF 输入电容往高阻节点一搭，fc 立刻掉到几百 kHz——你以为电路振荡，其实是你把它改成了振荡器。测高阻节点必须 ×10 + 短地。
运行三个 C 程序前，先在控制台执行 chcp 65001，否则中文输出全是乱码。
