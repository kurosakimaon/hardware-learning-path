# 第 2 关：炼气期 · 模拟电路

老师傅把一块"有声音但全是噪声"的板子拍在你面前，说：修好它。

## 一、模块简介

徒弟，上一关你画得出电路、算得出分压、KVL KCL 写得比谁都快。
很好，师傅现在要告诉你一句不太好听的话：

> ◆ 从这一关开始，你算的"对"，和板子上跑的"对"，
>   是两个东西。◆

为什么？因为模拟电路里没有一个元件是"理想"的。
你写的 10kΩ 电阻，实际上是个 10kΩ + 0.5pF 电容 + 一点温漂 + 一点噪声；
你写的"运放"，实际上是一个增益只有 10 万倍、带宽只有 1MHz、
输出还撞不到电源轨、输入还要偷 50nA 电流、开机还自带 2mV 误差的
**有缺陷的放大器**。教科书把这些全抹掉了，因为抹掉了才好教；
板子不会把它们抹掉，所以板子会冒烟。

师傅不带你去背公式，公式你都会。师傅带你去**算账**：
  这个电容为什么要挨着芯片引脚？——因为回路电感每 10mm 就有 8nH，
    瞬态电流 0.5A 一抖，就是 4V 的毛刺砸在你的"干净"电源上。
  示波器上那个振铃哪来的？——不是信号"反射"这么玄，
    就是探头地线夹那 100nH + 走线电感，跟芯片引脚电容谐振了。
  板子冒烟是哪一步算错了？——多半是这一关要教你算的那几笔账：
    LDO 的热、DCDC 电感的峰值电流、电解电容的纹波电流、整流桥的开机浪涌。

所以第一件活儿，不是让你设计，是让你**修一块板子**：

  一块音频小功放，声音有，但背景"嗡——"，还带"哒哒哒"的高频串扰。
  师傅带你一路查下去，你会发现这板上把本关的坑几乎踩全了：
    整流电容离桥式整流 6cm 远，走线绕了个弯 → 开机浪涌把地搅成一锅粥；
    运放同相端只有 1MΩ 到地，输入偏置电流在这颗大电阻上压出几十 mV，
      再被闭环增益放大 → 输出被慢慢顶到正轨，前级整个工作在截止区，只剩"噪声"能过；
    为了"滤掉噪声"在运放输出直接并了 100nF 到地 → 自激，那个"哒哒哒"
      就是它，你以为是干扰，其实是它自己在振；
    基准源用了一个电阻从 5V 分压下来的 → ADC 读数跟着负载电流一起抖，
      因为分压电阻 100k 的输出阻抗根本带不动 ADC 采样电容；
    最后那个"嗡——"：模拟地和数字地画成一个环，DCDC 的开关电流
      从你的麦克风地线回去了。

修完这块板子，你就入门了。剩下的就是把"为什么"用数字算一遍，
算到你以后看见原理图就自动开始算账。本关的 3 个 C 程序就是
给你算账用的算盘，2 个 HTML 是给你看清波形的显微镜。

## 二、为什么模拟电路是硬件的分水岭

师傅见过太多人，数字部分写得飞起，一到模拟就"玄学"。为什么？
因为数字和模拟的**世界观不一样**：

  数字电路：状态只有两个，抗噪声能力靠噪声容限（几百毫伏的裕量），
    错一个 bit 就是 0 和 1 的区别，仿真器说你过了就过了。
  模拟电路：状态是连续的，你的有用信号可能只有 200µV，
    而噪声底 50µV —— 你要在**连续量**里争那 6 倍的差别。

由此带来三件事，是本关真正的门槛：

1. **理想模型是有适用范围的，而且范围经常不覆盖你的工况。**
   "虚短虚断"是反馈深度够深时的近似：环路增益 T = A_ol·β。
   T=100 时误差 1%，你可以当理想；T=1 时误差 50%，你再用理想模型
   就是在骗自己。频率一高，A_ol 按 −20dB/十倍频掉，T 就没了——
   所以同一个电路，1kHz 算得对，1MHz 就完全不是那回事。
2. **每个指标都是别的指标的代价。**
   增益做高 → 带宽掉（GBW 守恒）；带宽做高 → 噪声和功耗涨；
   输出驱动大容性 → 相位裕度掉 → 振；滤波做陡 → 建立时间和过冲来；
   LDO 压差做大 → 效率线性掉、热线性涨。模拟工程师的本事不是
   知道哪个方案"最好"，是会**算这笔交换账**并挑一个能交差的折中。
3. **误差要按链路累加，而且要按最坏值和最坏值同时出现来算。**
   失调 2mV × 增益 100 = 200mV；温漂 5µV/℃ × 40℃ × 100 = 20mV；
   1/f 噪声在 10Hz 处可能比宽带噪声大十倍；参考源 250ppm 在 12 位上
   就是 1 位（25ppm 约 0.1 位）。链路里每一位有效位都是有人"付过钱"的：付的是带宽、
   功耗、成本、面积。你少付一笔，精度就从你没看的那一格漏走。

师傅说句实话：**这就是硬件岗的分水岭**。数字不会的，你能算；
别人遇到噪声说"再画一版试试"，你能说"是 50Hz 工频从传感器屏蔽层
进来的，因为单端接地，加一级仪表放大器 + 输入 fc=15Hz 的滤波，
能压 10dB"。这一关要给你的，就是这种"能算、能说、能改"的能力。

## 三、学习目标（学完你要能做到，逐条自检）

1. 给一个 **0~3.3V 的 ADC 采集 4~20mA 信号**，你能自己算出：
   采样电阻（100Ω → 0.400~2.000V）、后级增益（1.5 → 0.600~3.000V，
   留 0.3V 上限余量）、偏置/参考怎么来、输入 RC 的截止频率该取多少
   （想压 50Hz 工频 10dB，一阶就得 fc≈15Hz，不是"随手 1µF"），
   并且算出这套取值下 ADC 的每 LSB 对应多少 µA。
2. 说清**虚短虚断什么时候成立、什么时候崩**：能算反馈系数 β、
   环路增益 T，能说出"增益 100、GBW 1MHz 的同相放大器在 20kHz
   处实际只剩 45 倍（44.71）并且带了 63° 相位滞后"这类具体结论。
3. 拿到任意一个运放手册（A_ol、GBW、SR、输出摆幅、Ib、Vos），
   能在 5 分钟内判断它在你这个增益、这个频率、这个负载下
   **会不会削波、会不会压摆率受限、会不会撞轨**。
4. 设计一个 LDO 或 Buck：给定输入范围/输出/负载，能算出 LDO 的热耗
   与结温（并把封装热阻算进去！）、Buck 的占空比、电感纹波电流、
   峰值电流、感值、输出纹波与 ESR 的关系，最后给出**带降额的选型清单**。
5. 设计一阶 RC 和二阶 Sallen-Key 低通：会算 fc 和 Q，知道 Q=0.707
   和 Q=2 在波特图和阶跃上差在哪，能根据采样率倒推抗混叠截止频率。
6. 会排**精度链路**：失调、温漂、1/f 噪声、参考源 ppm，会把它们
   折算到同一端（ADC 输入端或传感器端）加总，说出"我的 12 位实际
   只有 10.2 位有效，漏在哪一格"。
7. 看到一板子噪声，能有条理地分诊：工频？开关频率？地弹？自激？
   并用示波器的正确姿势（×10 档、短地线、带宽限制）而不是
   "拿探头随便一搭"去看。

## 四、文件列表与学习重点

一共 7 个文件：3 个 C 算盘、2 个 HTML 教具、1 个课本、1 个导航页。
顺序别乱：先把"非理想"三件套（二极管/运放/电源）的数字算出来，
再用动画把波形看进眼睛里。

三个 C 程序都用同一套命令编译（纯 C17，无第三方库）：
`gcc -std=c17 -O2 -Wall -Wextra xxx.c -o xxx.exe`。
运行前**先在控制台执行 `chcp 65001`**，否则中文输出全是乱码。

**index.html** ← 本模块导航页（双击就能开）
  重点：先看它，知道每个文件干什么、按什么顺序啃、坑在哪。

**01_diode_rectifier.c** ← 二极管：从方程到开机烧桥
  重点：牛顿迭代解二极管方程（Is、n、Vt、Rs 都可改），看工作点
  到底落在哪；数值仿真半波 / 全波 / 桥式整流的输出波形，量出
  纹波峰峰值、二极管**导通角**、峰值浪涌电流；改电容和负载看数字怎么变；
  顺带算稳压管限流电阻与功耗。盯这几处输出：
    滤波电容越大纹波越小，但二极管峰值电流越大 —— 同一件事的两面；
    开机浪涌取决于合闸相位：过零合闸约稳态峰值的十几倍，峰值合闸可达几十倍，
    0.15Ω 源阻抗下能冲到 60A 以上——这就是烧桥的原因；
    半波整流的二极管反向耐压要吃约 2×Vpeak，桥式只吃约 1×Vpeak（实际还低一个二极管压降）。
  编译：

## 五、学习建议与常见坑（师傅挨个敲过的那几棒）

先说学习建议，就三条：
  1) 每个设计先手算一遍，再用这几个程序对答案。算不一致就去找原因，
     那才是你涨本事的时刻；程序只是算盘，别让它替你思考。
  2) 看到任何运放，第一件事查手册三个数：GBW、SR、输出摆幅。
     这三个数决定 80% 的"翻车"，Vos/Ib/噪声是第二梯队。
  3) 手边留一张纸，专门记"我以为…结果…"。模拟工程师的护城河
     就是这本"我以为"的清单。

坑，师傅给你列 12 条，条条见血：

1. **运放输出直接接大容性负载 → 自激。**
   在输出与地之间"随手"并 100nF 滤波，等于在反馈环里塞了一个额外极点，
   相位裕度掉光，跟随器变成振荡器。02 里那个二阶模型给你算了 Q 和过冲：
   容性负载 + 高输出阻抗 = Q≈1.8（ζ≈0.28），约 40% 过冲 + 长振铃。
   正确姿势：输出串 10~100Ω 隔离电阻（电阻在环路内，直流精度不受影响），
   或选手册写了 "unity-gain stable into capacitive loads" 的轨到轨输出级。

2. **同相放大器不给同相端直流偏置通路 → 输出被顶到轨。**
   输入串了个耦合电容，同相端只接了个 1MΩ？偏置电流 50nA 流过
   1MΩ 就是 50mV，再乘增益 11 = 550mV 直流偏到输出上；要是回路电阻
   更大、或者根本没有直流通路，偏置电流无处可去，直接把输出顶到轨。
   同相端对地电阻取 R1∥R2（02 会打印建议值），这叫**回路电阻平衡**。

3. **单电源用了双电源的公式。**
   双电源下输出可以摆到 0V，单电源 0~5V 下"输出 0V"意味着晶体管
   进线性区尽头——轨到轨运放也只是"轨到轨输出"，手册写
   "0.005V ~ (V+)−0.005V"那是空载；带 10kΩ 负载时可能是 0.05V，
   灌电流方向更差。0~3.3V ADC 前端如果指望输出真的到 0V，
   你的下三段读数就全是废的。单电源电路要主动留 headroom，
   并把"信号最低点"抬到运放摆幅之上。

4. **把运放当理想运放在 1MHz 下算增益。**
   GBW=1MHz、增益 100 的电路，−3dB 带宽只有 10kHz。你在 1MHz 处
   算出"增益 100"，实际开环增益本身已经只剩 1 倍，环路增益没了，
   电路退化成一个分压器 + 一个跟不上的放大器。**先算 f_cl = GBW/NG**，
   凡是工作频率接近 f_cl 的方案，一律重来。

5. **压摆率当带宽用。**
   f_3dB 够不代表正弦不失真。满幅 V_peak 需要 SR ≥ 2π·f·V_peak：
   SR=0.5V/µs 的运放做 10Vpp（V_peak=5V）输出，
   f_max = 0.5e6/(2π·5) ≈ 15.9kHz。超过它就变三角波，
   而你的示波器上看起来"还是有波形啊"——谐波已经烂透了。
   全功率带宽和 −3dB 带宽是两本账，分开算。

6. **LDO 只算 P=(Vin−Vout)·I，没算封装热阻 → 过温保护/烧毁。**
   470mW 听着小，SOT-223 的 θja≈105℃/W（没有铺铜的保守值），
   就是 +49℃；环境温度 55℃ 的机箱里，结温 104℃，接近 125℃ 限制，
   再加上旁边还有个发热主控，热耦合一来就去打嗝了。
   算热必须走 Tj = Ta + P·θja，并且 θja 要按**你实际的铺铜和风速**打折，
   手册上那个 25℃/W 是 EVM 上吹出来的。

7. **电解电容只看容值，不看 ESR、纹波电流和寿命。**
   整流滤波那一路，纹波电流是"真电流"，在 ESR 上变成热：
   P = I_rms²·ESR。电解电容的寿命大约**每降 10℃ 翻一倍**，
   105℃/2000h 的料在 85℃ 按每降 10℃ 翻倍的规律约 8000 小时，塞在发热源旁边就倒一半。
   低温环境下 ESR 会涨好几倍（这正是"冬天冷启动坏电源"的经典原因）；
   还有极性：整流桥反接、或者被并联的陶瓷电容分走太多高频导致它"没活干"
   但仍在发热，都是坑。要么按手册纹波电流降额，要么用聚合物电容。

8. **DCDC 电感按平均电流选饱和电流。**
   电感手册给的是 I_sat（电感值掉 30% 那个电流）和 I_rms（温升电流）。
   你 1A 输出、纹波 40%，峰值就是 1.2A，瞬态负载跳变时还会更高——
   选 1.0A 饱和的电感就是等着磁芯饱和：饱和后 L 骤降，纹波暴涨、
   开关管电流尖峰、效率跳水、EMI 爆炸。规则：**I_sat ≥ 1.3 × I_peak(最坏)**，
   峰值要用最小输入电压 + 最大负载 + 瞬态一起算。

9. **同步整流的死区与体二极管、异步整流的肖特基压降，算效率时忘了。**
   12V→1V 大电流的 Buck，异步肖特基 0.35V 压降在 3A 输出、D=0.083 时
   就是 (1−D)·Vf·Iout = 0.917×0.35×3 ≈ 0.96W，单只 SOT-23 肖特基（约 0.5W）根本扛不住——
   这就是低压大电流必须同步
   的原因；而同步整流的死区时间走体二极管（0.7V）以及 Rdson 随温度涨，
   又要重算。任何效率估算先把损耗分项列出来，别拿"典型 92%"糊自己。

10. **示波器探头 ×1 档把被测电路带宽拖死，长地线夹制造振铃。**
    ×1 档输入电容 100~150pF，往高阻抗节点一搭，fc 立刻掉到几百 kHz，
    你以为电路振荡，其实是你把它改成了振荡器。测高速/高阻节点必须 ×10
    （10~15pF）+ 短地（弹簧地针或接地环），地线夹那 100nH 环路电感
    是"示波器上独有的振铃"的主要来源。顺带：开 20MHz 带宽限制再测噪声，
    不然你量到的"电源噪声"有一半是空间耦合的射频。

11. **基准源用两个电阻分压 5V 来做，还从远处绕一圈走线。**
    ADC 的采样电容在采样瞬间要充电，瞬时电流能到 mA 级；
    100kΩ 分压的输出阻抗 ≈ 50kΩ，采样瞬间电压直接被拉走，
    读数随负载电流跳动（"地弹 + 参考抖动"的组合拳）。
    基准必须用专门基准源或低阻 + 大电容（10µF + 100nF，**紧贴芯片引脚**），
    参考走线走单独一条、不许有别的回路电流穿过，
    地要用星型/单点，别形成环路。

12. **"先随便画一版，不行再画一版"。**
    数字板这么干可以，模拟板不行。模拟板的性能一半在布局：
    反馈电阻要挨着引脚（走线电容进反馈环就是相位损失）、
    反馈环路包围的面积要最小（那是个单匝环形天线）、
    功率回流路径不能从信号地下面穿。
    03 里那句"纹波电流的回路面积"就是这个意思。画之前先想清楚
    每个回路的电流走哪条路、围多大面积。

## 六、老师傅的家庭作业（5 道，全都要动手）

1. **4~20mA → 3.3V ADC 全链路设计（必做）。**
   给定：三线制变送器、12 位 ADC（0~3.3V 参考）、采样率 1kSPS、
   要求抑制 50Hz 工频至少 10dB、系统精度 ±0.5%FS。
   交：采样电阻取值与功耗、增益与偏置网络电阻（取 E24 系列实际值）、
   输入滤波 fc 与 R/C 取值、用 02 验证所选运放在你的增益和带宽下
   误差 < 0.05%、折算到电流的 LSB 分辨率、以及你为 0.5% 精度
   挑的电阻精度与温漂等级。用 `02_opamp_lab.c` 的模型逐项核对。

2. **把 `opamp_animator.html` 玩到"能预判"。**
   先自己预测：拓扑=同相、R1=10k、R2=990k（增益 100）、GBW=1MHz、
   SR=0.6V/µs、电源 ±15V、输入 10mV/20kHz。输出幅度、波形形状、
   诊断结论各是什么？写下答案再点 preset 和拖动滑杆验证。
   然后调参数把电路救回"不失真"，至少给出两种不同思路（降增益 / 换运放 /
   降幅度 / 降频）并说明代价。

3. **手算 + 程序对拍 Buck 电感。**
   12V→3.3V、1A、开关频率 500kHz、目标纹波电流 = 30% 负载。

4. **给"噪声板"写一份分诊报告（1 页）。**
   用本关学的分类法（工频 / 开关频率 / 地弹 / 自激 / 参考抖动）
   为"有声音但全是噪声"这块板子写：现象、你测什么、预期看到什么、

   幅度 8mVpp，一阶输入滤波 fc=15Hz 可压 10dB"。

5. **精度链路预算表。**
   一个 ±10V 差分采集、增益 0.1、目标 16 位有效（0.0015%）：
   把运放 Vos、Vos 温漂、Ib 在信号源内阻上的压降、电阻 25ppm/℃、
