## 一、模块简介

徒弟啊，前四关你把元器件、电源、信号、接口都认全了，
手里攥着一堆"点"。这一关开始，你要把点连成面——
画一块真正能下单、能上电、能过认证的板子。

师傅先交代一件事：这一关的第一块练习板，
我只要你在**两层板**上放三样东西——一个 LDO、一颗 MCU、一组 LED。
别嫌寒酸。三层四层的东西你现阶段画不出也验不动，
两层板把所有矛盾都摊在明面上：

1. 顶层走线，底层必须是完整的地——回流路径这个词，
   两层板是唯一能让你用肉眼"看见"的层数。
2. 空间紧张，线宽、间距、去耦位置全要你自己抠，
   没有第三层给你"藏"问题。
3. 画完可以直接打样，三十块钱两块，
   错了焊两块新的，对了它就是你后面所有实验的底板。

这一关一共 8 个文件：3 个 C 计算器（编译了跑给你看数字）、
3 个 HTML 交互教具（双击就玩）、1 份课本（就是它）、1 个导航页。
学完你能做到：拿到一张原理图，自己定叠层、定线宽、摆去耦、
控回流，画出来的板子工厂不骂人、认证不返工、
上电不冒烟——至少大概率不冒烟。

## 二、为什么 PCB 是硬件工程师的分水岭

面试的时候，原理图画得漂亮的人一抓一大把，
能独立扛一块四层板从布局走到量产的，十个里挑不出两个。
为什么？因为 PCB 是硬件里唯一一个**所有物理规律同时上门**的环节：

- 电流大了要发热——线宽和过孔是**热学题**（01 文件算给你看）；
- 边沿快了线就不是线，是传输线——阻抗、时延、反射是**电磁学题**（02）；
- 高频电流永远找最小环路——回流路径、去耦是**天线设计题**（02/03）；
- 噪声要么传导要么辐射——EMC 测试是把你的布局**公开处刑**（03）；
- 最后还有一关：工厂的制程能力、装配的可行性——**DFM 是社会题**。

原理图错了，改一根线五分钟；布局错了，改一版板子两周加两千块，
错过认证窗口再赔一个月。所以行里有句话：
**原理图决定功能上限，PCB 决定你能不能活着到达那个上限。**
数字玩得再花，板子辐射超标、电源纹波炸麦、过孔烧开路，
在客户眼里你就是不会硬件。这一关，就是把你从"会画"逼到"会设计"。

## 三、学习目标

学完本模块，你要能做到：

1. 用 IPC-2221 公式（或 01 计算器）口算 1 oz 外层线的安全载流，
   说清"0.3mm 线走 1A"为什么是找死，并给出降额后的工程值
2. 拿到一个叠层（比如 4 层 SIG-GND-PWR-SIG），
   对任意一层说出：它参考谁、50Ω 微带该多宽、90Ω 差分该多宽多距
3. 用"总延时 > Tr/6"判断一条线要不要按传输线处理，
   用 3W 规则量化串扰能降多少 dB，说清 NEXT 和 FEXT 谁跟谁
4. 给一颗 100MHz 时钟的 MCU 摆去耦：每颗电容离引脚多远、
   容值怎么错开、反谐振峰怎么压，全部有数字依据而不是"手感"
5. 画出回流路径图：1kHz 电流怎么走、100MHz 电流怎么走、
   跨分割之后环路面积涨几倍、辐射涨几 dB，账算得出来
6. 拿到工厂的叠层_capability 表，判断 0.12/0.12mm 线宽能不能做、
   盲埋孔加不加钱，交付前用 DFM 清单自查，别等工程师打电话来骂
7. 首件板回来，按"量阻值→串灯泡→分域上电"的流程点亮，
   而不是插上去赌运气

## 四、文件列表与学习重点

一共 8 个文件。3 个 .c 是算盘，3 个 .html 是教具，
tutorial.md 和 index.html 是地图。顺序别乱：

**index.html** ← 本模块导航页（双击就能开）
  重点：先看它，知道每个文件是干嘛的、按什么顺序啃

**tutorial.md** ← 你正在读的课本
  重点：每个 .c 跑完必须回来对一遍"预期输出"和常见坑

**01_trace_and_via.c** ← 走线与过孔的载流/温升计算器（★ 主菜）
  重点：IPC-2221 公式 I = k·ΔT^0.44·A^0.725（外层 k=0.048、内层 0.024）；
  降额 0.7 的构成；过孔孔壁铜圆筒热模型。编译运行（先 chcp 65001）：

```powershell
gcc -std=c17 -O2 -Wall -Wextra 01_trace_and_via.c -o 01_trace_and_via.exe
.\01_trace_and_via.exe
```

  必须看到的锚点数字：1 oz 外层 0.30mm、温升 20℃ → 裸值 1.36A、
  降额后 **0.95A**（工程上按 0.7~0.9A 记）；单颗 0.3mm 过孔走 2A
  保守模型温升 **64℃**；5A 电源 → 1oz 外层 **2.97mm + 9 颗孔**。
  跑完自己改 main 里的电流表，加一档 12A 看看线宽多离谱。

**02_impedance_crosstalk.c** ← 特征阻抗、时延与串扰计算器（★ 主菜）
  重点：微带线 Hammerstad 公式、带状线公式、差分 Zdiff=2·Z0·(1−k)、
  Bogatin 串扰模型 k=8·e^(−πS/2H)。编译运行（先 chcp 65001）：

```powershell
gcc -std=c17 -O2 -Wall -Wextra 02_impedance_crosstalk.c -o 02_impedance_crosstalk.exe
.\02_impedance_crosstalk.exe
```

  必须看到的锚点数字：50Ω 微带在 1.6mm FR4 上 **W≈3.04mm**、
  0.8mm 上 **W≈1.50mm**、4 层板 0.2134mm 介质上 **W≈0.35mm**——
  这三个数记住，以后看到 2 层板画 0.3mm"高速线"你就知道那是天线；
  USB 90Ω 差分在 4 层板外层：W=0.38mm、净距 S=0.66mm；
  3W 规则实测值 **−18.9dB**。

**03_decoupling_emc.c** ← 去耦电容与 EMC 滤波器计算器（★ 主菜）
  重点：电容 RLC 串联模型、自谐振 f0=1/(2π√LC)、安装电感 1mm≈1nH、
  多容值并联的反谐振峰、目标阻抗法反推 ESL 预算。编译运行（先 chcp 65001）：

```powershell
gcc -std=c17 -O2 -Wall -Wextra 03_decoupling_emc.c -o 03_decoupling_emc.exe
.\03_decoupling_emc.exe
```

  必须看到的锚点数字：0603 100nF 自谐振 **19MHz**、100MHz 处剩 0.43Ω；
  电容离引脚 10mm → 100MHz 阻抗恶化 **9.1 倍**；
  三颗 100nF 并联 vs 10µF+100nF+1nF：前者带宽纹丝不动，
  后者 Z<0.5Ω 覆盖 100kHz~253MHz 但有 5.8Ω 反谐振峰。

**stackup_lab.html** ← 叠层实验室（教具）
  重点：2/4/6 层切换 + 三个预设（两层经济型、四层标准型、四层反面教材）。
  把信号层参考改到电源层、改到"无参考"，看体检结论怎么标红；
  每层的 50Ω 线宽实时算给你看——公式和 02.c 是同一套。

**return_path_animator.html** ← 回流路径动画（教具）
  重点：1kHz/100MHz 切换 × 平面完整/跨分割切换，四格对照。
  看 100MHz 电流怎么贴着信号线底下走、跨分割怎么被迫绕出大环路，
  下方"环路账本"用 10log(面积比)+20log(频率比) 把辐射涨幅算成 dB。

**decoupling_animator.html** ← 去耦阻抗曲线（教具）
  重点：亲手摆 1~4 颗电容（容值/封装/走线长度都可改），
  实时看并联 Z-f 曲线。四个预设里"反面教材：三颗同值"和
  "100nF 离引脚 10mm"务必亲手拖一遍，数字和 03.c 对得上。

## 五、学习建议与常见坑

### 环境与准备

三个 .c 只依赖 C17 标准库，没有任何第三方包、不联网、不碰硬件。
Windows 下用 MSYS2 的 gcc（师傅这台是 16.2，C17 需 ≥8）编译即可；
中文输出如果在控制台显示成乱码，运行前先执行：

```powershell
chcp 65001
```

三个 HTML 是纯离线单文件：没有 CDN、没有外部字体、没有 js 库，
断网双击照样能玩。教具里的公式和 .c 里是同一套，
数字对得上——对不上就是坏了，来告诉师傅。

### 学法（跟学 C 一个套路）

1. 先跑：每个 .c 编译跑通，别跳步；
2. 对数：输出对一遍本文第四节的锚点数字，对不上说明环境或文件有问题；
3. 改：改 main 里的参数——线宽、介质厚、容值——**先猜结果再验证**；
4. 玩：三个 HTML 每个预设都点一遍，把"红色警告"攒够十个再往下走；
5. 画：学完在纸上给"两层板 + LDO + MCU + LED"画一版布局草图，
   用本关公式标注线宽、去耦位置、回流假设——这是作业的门票。

### 每个 .c 的输出怎么读

**01 的输出是四张账表**，读法是"先找行、再看列、最后核假设"：

- 载流表每格是"裸值/降额值"两个数。**设计只认降额值**，
  裸值只用来说明 IPC 原表有多乐观（电镀公差、密闭外壳、阻焊覆盖
  全没算进去）。列头的 ΔT 是"允许温升"不是环境温度，ΔT=20℃
  在密闭外壳里等于环境 65℃——先想清楚你的 ΔT 假设再看数。
- 过孔部分先给直流电阻（0.3mm 孔 1.37mΩ，折合 0.86mΩ/mm，
  其实比 0.3mm/1oz 走线的 1.64mΩ/mm 还低；它的瓶颈是散热面积小，不是直流电阻），
  再给单孔 2A 的两种热模型：64℃（孤立孔）对 8℃（两端接大铜皮）。
  查表时按保守值做决定，8℃ 那个是别人替你焊接良好时的运气。
- 末尾"推荐方案表"是拿来直接抄的：1A→0.32mm+2 孔、2A→0.84mm+4 孔、
  5A→2.97mm+9 孔。抄完记得回一句：net class 设了吗？

**02 的输出是"扫描表 + 反解 + 场景题"三段**：

- 三张 Z0 扫描表对照着看：同样 50Ω，H 从 1.6mm 缩到 0.21mm，
  线宽从 ~3mm 缩到 ~0.35mm。这一眼看懂"细线控阻抗"的前提是薄介质。
- 反解段（50Ω/90Ω 差分）每行都带量级自查提示——如果你的输出
  和期望差一个数量级，先怀疑公式实现，别急着信屏幕。
- 串扰场景题里 NEXT/FEXT 两列：先看 dB 再换算 mV@3.3V。
  159mV 还不足以单独把 3.3V CMOS 从 0V 抬过 0.8V 的 VIL，但它已经吃掉
  低侧噪声容限（约 0.36V）的四成多；叠上地弹、反射或阈值漂移就可能翻错，
  所以不能拿"没到门限"当免死金牌。

**03 的输出是"一颗电容 → 装上天 → 并联 → 滤波器"四步**：

- 单颗表：f0 就是"有效频段"的边界，超出就是电感。
  100nF 的 f0 只有 16~22MHz，记住这个反差。
- 安装电感表：恶化倍数那一列是"离引脚 10mm 等于没放"的数学版本。
- 方案 A/B 对比：B 的反谐振峰一栏写"无（同值并联）"——
  无反谐振不代表更好，覆盖宽度没变，只是三颗挤在同一个坑里。

### 常见坑（每一条师傅都赔过钱）

1. **【高速信号跨分割，回流绕远路】**
   信号线从完整地区爬到"没铜区"上空，100MHz 的回流被迫绕着分割走，
   环路高度从 1.6mm 变成约 18mm（面积约 11 倍）——return_path_animator 里
   账本直接算给你看：10·log₁₀(11.25) ≈ +10.5dB，已经是一个数量级的恶化。
   修法优先级：改叠层让信号换参考层 > 挪线避开分割 > 桥接电容（下策，
   只治 200MHz 以下，且电容自己也要有回流）。

2. **【去耦电容"放了"，但离引脚 10mm】**
   引脚→过孔→绕线→焊盘，回路 10mm ≈ 10nH，100MHz 处 6.7Ω——
   这颗电容对高频等于没放。电容不是摆件，是环路的一部分，
   量的是"回路总长"不是直瞄距离。先脚后孔、能上背面不上同层。

3. **【电源线画 0.2mm，"能连上就行"】**
   01 的表：1oz 外层 0.2mm 降额后只有 0.71A（ΔT=20℃）。
   5V 主回路 2A 用 0.2mm 线，等于在家用电线里接了个细脖子，
   温升、压降、老化三头一起炸。电源线宽按"目标电流查表"定，
   并且要在 EDA 的 net class 里锁死，别让下一个接手的人改回 0.2。

4. **【地 split 单点连接滥用】**
   听说"模拟地数字地要分开"，于是把地-plane 切成两半留一个细腰。
   结果所有跨域信号的回流全挤过那个腰，细腰变成公共阻抗和天线。
   正确姿势：低速单点混板，地基本不 split，模拟区靠"分区布局 +
   单点电源"隔离；真要分，先确认没有信号线跨过缝。

5. **【晶振下面走线 / 晶振不包地】**
   晶振是板上最强谐波源之一，底下走线等于让 100MHz 直接耦合走。
   规则：晶振正下方所有层禁走线（底层地别挖），晶振一圈包地+打孔缝合，
   负载电容的回路先回晶振脚、再就近下地。

6. **【参考层不完整还硬做阻抗控制】**
   阻抗公式的前提是"参考平面完整"。参考层被别的信号掏空一半，
   算出的 50Ω 只存在于计算器里——实际阻抗随掏空程度乱跳。
   顺序永远是：先保证参考完整（stackup_lab 体检到绿），再谈线宽。

7. **【覆铜乱接：GND 铜皮随手铺、随手接】**
   覆铜不接等于一块悬浮天线；接到脏电源上等于给噪声供电；
   细颈连接（一格铜皮带两根细脖子）高频上什么都不是。
   规则：大面积覆铜要么实心地、要么干脆删掉，连接用一排过孔，
   别让铜皮"看起来接了地"。

8. **【大电流路径上只打一个过孔】**
   0.3mm 过孔孔壁铜截面积约 0.02mm²，和 0.3mm/1oz 走线（0.0105mm²）同量级，
   但它的散热面积只有孔壁那一圈，温升远高于同截面走线，
   单孔 2A 保守模型温升 64℃，3A 破 150℃——量产高温老化开路全是它。
   多孔并联收益是 n^0.85 不是 n：1A 打 2 颗、2A 打 4 颗起步，
   大电流优先大孔/开窗加锡，而不是数着打十颗小孔。

9. **【丝印压焊盘、压过孔孔口】**
   油墨印到焊盘上，SMT 贴装虚焊、测试针扎脏；印到孔口，孔内残锡气孔。
   规则：丝印离焊盘/孔环 ≥0.15mm，位号宁可小一号也别骑线。
   DRC 不管这个，DFM 检查必挂。

10. **【铜皮孤岛、死铜不清】**
    孤立的铜岛浮在板上：感应耦合出悬浮电位，是窄带辐射源，
    也是 ESD 的随机放电路径。多数"玄学辐射超标"先查它。
    出厂前清岛规则设为最小面积，别舍不得那点铜。

11. **【DRC 全绿就发板，DFM 被打回】**
    DRC 查的是"电气对不对"，工厂查的是"我做不做得出来"：
    最小线宽/间距是工艺极限不是设计余量；0.15mm 以下孔要激光孔加钱；
    阻焊桥太窄做不出来；铜皮离板边不够会短路到金手指。
    发板前过一遍工厂的 capability 表和 DFM 清单，
    被工程师打电话骂一顿是小，排期延两周是大。

12. **【首件回来直接插芯片上电】**
    板子短路概率不为零，直接上电就是"烟花表演"，
    炸掉的芯片和现场心理阴影都是你的。
    流程：先不焊 IC，万用表量每路电源对地阻值（不是 0Ω 就行，
    几十 mΩ 大概率短路）→ 稳压电源限流 50~100mA 空载上电
    → 摸温度、量电压 → 一路一路域解锁 → 最后才插/焊芯片。
    01 文件末尾"老师傅收口"第 3 条就是它。

13. **【过孔 stub / 参考层切换不当，阻抗"突变点"】**
    1GHz 往上，1mm 的 stub 就是感性突变；换参考层的过孔没有
    相邻的地孔伴飞，回流瞬间断脸。不是要做 GHz 板就不管，
    而是知道：阻抗连续比阻抗准确更重要，突变点比 52Ω 伤人得多。

| 0.5Ω | 3.3V/100mV 纹波/200mA 的目标阻抗 | 03 |
| 150kHz | 传导测试起点，滤波拐点必须压在它下面 | 03 |

三句口诀收着：

1. **信号线走到哪，回流就在哪一层跟着走**——脚下没铜就是天线；
2. **电容不是摆件，是环路的一部分**——量回路总长，不量直瞄距离；
3. **DRC 绿不等于能造，能造不等于能过认证**——三道关卡三个清单。
