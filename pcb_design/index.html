PCB 设计与 EMC

原理图决定功能上限，PCB 决定你能不能活着到达那个上限。这一关练四件事： 叠层与回流（信号线走到哪，回流就在哪一层跟着走）、 载流与阻抗（线宽是热学题，线不是线是传输线）、 去耦与 EMC（电容不是摆件，是环路的一部分）、 DFM 与上电（DRC 绿不等于能造，能造不等于能过认证）。 8 个文件全部离线：gcc 编译即跑，HTML 双击即开。

⌨️ 编译速查（MSYS2 / gcc 16.2，零警告标准）

# 控制台中文乱码先执行：chcp 65001；三个示例逐条编译（-Wall -Wextra 必须零警告）
gcc -std=c17 -O2 -Wall -Wextra 01_trace_and_via.c -o 01_trace_and_via.exe
gcc -std=c17 -O2 -Wall -Wextra 02_impedance_crosstalk.c -o 02_impedance_crosstalk.exe
gcc -std=c17 -O2 -Wall -Wextra 03_decoupling_emc.c -o 03_decoupling_emc.exe
.\01_trace_and_via.exe          # 1oz/0.3mm/20℃→0.95A；单孔2A温升64℃；5A→2.97mm+9孔
.\02_impedance_crosstalk.exe    # 50Ω线宽 3.04/1.50/0.35mm；USB差分 W0.38+S0.66；3W→−18.9dB
.\03_decoupling_emc.exe         # 0603 100nF自谐振19MHz；离引脚10mm恶化9.1倍；同值并联带宽不扩

🪜 学习顺序（别乱）

  1. 读地图：通读 tutorial.md，知道为什么第一块练习板只有 LDO+MCU+LED，认识 13 个坑长什么样。
  2. 算载流：编译跑 01_trace_and_via.c，对锚点数字（0.95A、64℃、5A→2.97mm），然后改 main 里的电流表加一档 12A。
  3. 玩叠层：打开 stackup_lab.html，三个预设各点一遍，把每个红色警告的"为什么"说给自己听。
  4. 算阻抗：编译跑 02_impedance_crosstalk.c，重点记 50Ω 三个线宽（3.04/1.50/0.35mm）和 Tr/6 判据。
  5. 看回流：打开 return_path_animator.html，切四格对照，看懂环路账本里 20log(f) 那一项为什么吓人。
  6. 算去耦：编译跑 03_decoupling_emc.c，再用 decoupling_animator.html 把"反面教材"预设拖成正面教材——这一步做到位，去耦就算过关。
  7. 交作业：做 tutorial.md【六】的 5 道作业，毕业考是那张红笔回流自查的纸面板。

🕳️ 本关高频坑（完整 13 条在 tutorial.md）

高速线跨分割回流被迫绕出大环路，环路高度 1.6mm→约 18mm（面积约 11 倍，+10.5dB）。先改叠层，其次挪线，桥接电容是下策。
去耦电容离引脚 10mm回路 10mm≈10nH，100MHz 处 6.7Ω——这颗电容对高频等于没放。量的是回路总长，不是直瞄距离。
电源线 0.2mm"能连就行"1oz 外层 0.2mm 降额后只有 0.71A。线宽要在 EDA 的 net class 里锁死，否则换人接手就退回 0.2。
单颗过孔走大电流0.3mm 孔孔壁截面和 0.3mm 走线同量级，但散热面积只有孔壁，单孔 2A 保守温升 64℃。多孔并联收益是 n^0.85 不是 n。
参考层不完整硬做阻抗公式的前提是参考平面完整。顺序永远是：先体检到绿，再谈线宽。
DRC 全绿就发板DRC 查电气对不对，工厂查做不做得出来。发板前过一遍工厂 capability 表和 DFM 清单。
首件直接插芯片上电先不焊 IC：量电源对地阻值→限流 50~100mA 空载上电→分域解锁→最后才上芯片。
覆铜乱接 / 铜皮孤岛悬浮铜岛是窄带辐射源加 ESD 随机放电路径。大面积覆铜要么实心地，要么删掉。
