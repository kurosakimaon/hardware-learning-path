# 第 1 关：筑基期 · 电路基础

老师傅带你从零开始，一步一个脚印。
这一关不碰芯片手册、不画 PCB、不写一行寄存器，
就干一件事：**让你脑子里有个会流动的电流**。

---

## 一、模块简介：师傅为什么先让你焊 LED

徒弟，你进门第一天，师傅没给你示波器，没给你《模拟对话》，
甚至没让你碰万用表的电压档——
师傅丢给你一颗 LED、一个电阻、一个 5V 充电宝，说："点亮它。"

你当时肯定觉得这是在耍人。

现在告诉你为什么。

**第一，它逼你承认自己不知道电流往哪走。**
你小学四年级自然课就知道"电流从正极流向负极"，
所以你理所当然地以为，把 LED 两根腿怼到电源输出两端就完事了。
结果 LED 不亮。为什么？因为你把腿插反了。
你翻过来，亮了——但亮了三秒，手指被烫得缩回来，
LED 的腿发烫，光也变暗了。
这时候你才开始问出那个真正的问题：
**"电流到底有多大？谁决定它有多大？"**

这一问，就是电路分析的起点。
你手里那个充电宝不是"理想 5V"，它内部有内阻和限流；
那颗 LED 不是"用电器"，它是个非线性器件，
端电压从 1.9V 变到 2.3V，电流能翻十倍；
而那根你随手剪的铜线，电阻大概 8 毫欧，
于是回路里几乎全部的压降都压在 LED 上，
电流瞬间冲到两三安——充电宝在限流，LED 在烧自己。

**第二，它逼你算那个电阻。**
你回去问师傅，师傅在纸上写了一行：

```
R = (5V - 2.1V) / 0.010A = 290Ω  →  取 330Ω
```

然后问你三个问题：
- 为什么减 2.1V？（因为 LED 导通后端电压几乎被"钳"住，多的电压必须有人扛）
- 为什么是 10mA？（因为数据书写 20mA 是"最大"，不是"推荐"；10mA 已经亮得你睁不开眼）
- 为什么取 330 不取 290？（因为 290 不在 E24 系列里，你买不到）

这三个问题问完，你就已经摸到硬件工程师的核心思维了：
**理想值算出来只是第一步，
真实世界要你考虑内阻、容差、系列值、功耗、封装、成本。**

**第三，也是最要紧的：它让你以后每次看到一张原理图，
脑子里浮现的是"电流怎么走"，而不是"这堆符号叫什么名字"。**

后面你要学的东西——
运放为什么不能直接驱动 50Ω、
MOS 管的栅极为什么要串 10Ω、
I²C 上拉为什么不能一律 10k、
ADC 读出来的数为什么抖、
板子一上电 3.3V 就掉到 2.8V、
板子跑得好好的，手指一碰就复位——

**根子上全是这一关的东西。**
这一关不牢，后面每一关你都在背结论；
这一关牢了，后面每一关你都在推结论。

师傅见过太多人，能背 KVL、KCL，
考试九十分，
板子上电发现某个 100Ω 电阻烫手，
第一反应是"电阻坏了"，
而不是"我算错了，这里压降 × 电流 = 0.5W，0402 封装的额定只有 1/16W"。

这一关就是防你成为那种人。

## 二、为什么先建立"电流直觉"，再学公式

你大概会想：师傅，KVL、KCL、节点电压法、戴维南，
不都是公式吗，直接教公式不就完了？

不成。公式是**结论的压缩形式**，
你在没有直觉的时候记住它，
就等于在没有肌肉的时候背健身动作要领——练不出东西，还容易受伤。

师傅给你一套"物理画面"，以后所有公式都挂在这套画面上：

**① 电压不是"某点的属性"，是"两点之间的差"。**
电压的英文叫 potential **difference**，差。
说"A 点是 3.3V"，完整的意思是"A 点相对于我选的那个叫 GND 的点高 3.3V"。
GND 不是"地"，GND 是**你随手挑的参考点**，
你挑哪儿，哪儿就是 0V。
你把万用表黑表笔夹到板子左上角的 GND，红表笔夹到 3.3V，读数是 3.300V；
如果那个左上角 GND 和右下角 GND 之间走了 200mA 的电流、
中间铜皮只有 0.1Ω，你换个位置夹黑表笔，读数就变 3.280V。
**这 20mV 不是表不准，是那个"0V 点"本身不是同一个 0V。**

**② 电流必须有回路，没有回路就没有电流。**
这句话你背得出来，但你不信。
师傅问你：电池正极接一个电阻，电阻另一头悬空，电阻上有电流吗？
没有。
再问：电池正极接一个电阻，电阻另一头接一个大铜板（比如机箱），
铜板没有连回电池负极，有电流吗？
**还是几乎没有。**
但是——如果你手去碰那块铜板，就有了，电流从你身体流向大地，
再经过电池的分布电容流回。这就是为什么 220V 的火线你碰一下就出事，
哪怕它没有"回路"：**大地就是那半条回路。**
在板子上，这个效应的温和版本就是：
一根长走线对空气有 3~5pF 的寄生电容，
于是"悬空"的网线里真的可以有微小电流通过，
示波器夹上去就能看到波形——**电容通了高频。**
这一句你现在记住，第四关讲 EMC 时会回来找你。

**③ 电阻不是"阻碍电流的东西"，是"决定电流的东西"。**
在一个回路里，电流不是"从电源流出来，被电阻吃掉一点"。
电流是**整个回路同时被电阻决定**的：I = V总 / R总。
回路里加一个 1kΩ，全回路的电流一起变小，
不是"到那儿小一点"。
水流的比喻只能帮你一次：
水管里的水，不是流到细管才变慢的，是一整圈都变慢。

**④ 电源不是"永远输出那个电压"。**
5V 电源挂 10mA 时是 5.00V，挂 1A 时可能是 4.7V，
挂 1A 的**瞬间**可能先掉到 3.9V 再回来。
因为电源有内阻（输出阻抗），而且输出阻抗是**随频率变的**：
低频时靠反馈环路稳住（低），
高频时反馈环路来不及反应（高，可能几欧姆甚至几十欧姆）。
**这就是"去耦电容"存在的全部理由**：
芯片在几十 MHz 上"看到"的电源内阻是几十欧姆，
而它需要几毫安的瞬时脉冲——电压必塌。
旁边放个 100nF，在高频上"临时当电源"，
因为电容的阻抗 1/(2πfC)，在 30MHz 时 100nF 只有 0.05Ω。
第三关讲电源完整性，这话我再说一遍。

**⑤ 万用表、示波器探头，都是电路的一部分。**
数字万用表直流电压档内阻通常是 10MΩ（老式指针表是 20kΩ/V，
10V 档只有 200kΩ，量高阻电路直接量错）。
你把表笔搭上去，就等于并在被测点上并联了一个 10MΩ。
量 1k/1k 的分压？影响可以忽略。
量 10M/10M 的分压？10M 表笔并上去，下臂变成 5M，
读数从 1.65V 掉到 1.10V（−33%）。
**"表笔一搭电压就不对了"——这不是表坏了，是你在改电路。**

这五条，你现在可能觉得是常识。
信师傅一句：**这五条，绝大多数工作三年的人都说不利索。**
你不光要说得利索，你要能在图上"看见"它们。

## 三、学习目标（可检验）

学完本模块，你要能做到下面七条。
"能做到"的意思是：有人给你一张图，你能给出**带单位的数字**，
而不是"大概""应该""差不多"。

1. **能一眼指出电流回路。**
   随便给一张原理图，你能用笔描出"电流从电源正极出发，
   经过哪些元件，怎么回到负极"，并且说得出"这里没有回路，
   所以这条线上的电流是 0"。

2. **拿到"电源 + 若干电阻"的图，能手算任意节点电压和任意支路电流，
   误差不超过 5%。**
   包括但不限于：串并联化简、分压、限流、上下拉。
   手算不出的，能用节点电压法（`01_node_solver.c`）列方程，
   并解释每一个方程是哪一条 KCL。

3. **能用戴维南等效把任何一个"电阻网络 + 电源"塌缩成一个电压源串一个电阻，
   并用它判断"后级能不能吃下这个信号"。**
   具体检验：给你一个 10k/10k 分压，你要立刻说出
   "等效源是 1.65V，内阻是 5kΩ"，
   并且知道接 10k 负载时输出被拉到 1.10V（掉 33%）。

4. **看到 R 和 C，能立刻说出 τ = RC，并能在脑子里做 3τ / 5τ 换算。**
   给 10k + 100nF，你要说"τ = 1µs……不对，是 1ms，
   5τ = 5ms，所以这个电路最快只能处理 200Hz 量级的变化"。
   给 10k + 10pF，"τ = 100ns，走 1MHz 的信号没什么问题"。

5. **能算出"某个电阻应该选什么封装"。**
   P = V × I = I²R，然后对照：
   0402 ≈ 1/16W(0.0625W)，0603 ≈ 1/10W(0.1W)，0805 ≈ 1/8W，1206 ≈ 1/4W。
   算出 0.15W 却用 0402 —— 你要能立刻警觉，
   说"这个电阻会在半小时内把焊盘旁边的板子烤黄，
   然后在三个月后开路，且现场查不出来"。

6. **能给一个具体需求选出一个具体电阻值，并讲清楚折中过程。**
   例如"给 MCU 按键选上下拉/消抖电阻"、
   "给 3.3V→1.65V 采样选分压电阻"、
   "给 I²C 选上拉电阻（100k 上拉 + 400kHz = 边沿拉不起来）"。
   要能说出漏电流、功耗、噪声、ADC 输入阻抗、边沿速度这五件事
   分别在往哪个方向扯。

7. **能解释电容在四种场景下分别在干什么，并算出关键数字：**
   上电延时（τ 决定延时长度）、
   按键消抖（τ 决定"多少毫秒的抖动被吃掉"）、
   PWM 变 DAC（τ 远大于 PWM 周期才有平滑效果）、
   电源去耦（在噪声频率上电容的阻抗是否足够低）。

**`01_node_solver.c` ← 通用节点电压法求解器（★ 主菜，最重要）**

  重点：这个程序会自己列方程、自己解方程，
  你只要给它一张"网表"（哪个元件接在哪两个节点之间、阻值多少）。

  编译（PowerShell，在本目录下）：

  ```powershell
  chcp 65001   # 先把终端切到 UTF-8，否则中文输出会乱码
  gcc -std=c17 -O2 -Wall -Wextra 01_node_solver.c -o 01_node_solver.exe
  .\01_node_solver.exe
  ```

  你会看到四组结果，逐条盯着看：

  - **① LED 限流**：5V 电源，LED 用"恒压降模型"（导通压降 2.1V）串 330Ω，
    打印出电流约 8.8mA、电阻上压降、电阻功耗约 25.5mW。
    然后换成 1kΩ，看电流掉到多少、亮度（正比于电流）掉到多少。
    再换成 100Ω，看功耗涨到 84mW——
    **这就是 0402 封装（62.5mW）会被烤的位置。**

  - **② 分压带负载（负载效应）**：先打印空载的 10k/10k 输出 = 1.650V，
    然后依次挂上 1M、100k、10k、1k 的负载，
    打印实际输出和误差百分比。你会亲眼看到
    挂 10k 时输出只剩 1.100V、误差 −33.3%。
    **这一张表，是本关最值钱的一张表。**

  - **③ 惠斯通电桥**：先跑平衡的（四臂都是 10k），
    中间检测支路电流打印出来是 0（或 1e-17 量级的数值噪声），
    这就是"电桥平衡时检流计无电流"。
    然后把一个臂换成 10.1k（模拟应变片形变 1%），
    输出变成毫伏级——
    **你会立刻明白为什么需要仪表放大器，
    而不是直接接 ADC。**

  - **④ 电源内阻的杀伤力**：同一个 LED 电路，
    把"理想 5V"换成"5V + 2Ω 内阻"，
    看节点电压掉多少；再并一个 100µF，看它只能救慢变化不能救快变化。

  看代码时重点看两处：
  一是 `buildStamp()` 那个函数旁边的注释——
  **为什么"节点电压法"本质上就是 KCL + 欧姆定律**：
  对每个节点，"流出的电流之和 = 0"，
  而每条支路的电流都可以写成 `(本节点电压 - 邻居电压) / 电阻`，
  于是未知量只剩节点电压，方程就是线性的。
  二是高斯-约当消元那段——
  别怕，就是一个带部分主元选取的三重循环，
  师傅写的时候也没用什么魔法。

**`02_rc_transient.c` ← RC 充放电数值仿真（★ 主菜）**

  重点：用欧拉法一步一步模拟电容电压怎么变化，
  同时打印解析解 `V = V∞ + (V0 - V∞)·e^(-t/RC)` 做对照，
  让你亲眼看见"数值方法"和"闭式解"能对上到 1e-3 以内，
  并且理解"步长选大了会怎样"（会发散、会飘，
  这是以后你做 SPICE 仿真、做电力电子仿真时的第一课）。

  编译运行：

  ```powershell
  chcp 65001   # 先把终端切到 UTF-8，否则中文输出会乱码
  gcc -std=c17 -O2 -Wall -Wextra 02_rc_transient.c -o 02_rc_transient.exe
  .\02_rc_transient.exe
  ```

  程序给你四样东西：

  - **ASCII 波形**：终端里用字符画出充电曲线，
    横轴时间、纵轴电压。丑，但你能一眼看出"指数"是什么形状——
    **不是 S 形，是从一上来最快、越走越慢。**
  - **误差校验表**：欧拉 vs 解析解，打印最大绝对误差。
  - **关键时间点扫描**：对每一组 R、C，
    打印到 1/3·VCC 和 2/3·VCC 的时间（555 定时器、施密特触发器的阈值）、
    以及 10%~90% 上升时间（= 2.197·τ，这个数字要背）。
  - **上电冲击电流**：一块板子上并了 N 个去耦电容，
    5V 直接怼上去，等效串联电阻 ESR 只有几十毫欧时，
    峰值电流是多少安。程序会打出那个让你头皮发麻的数字，
    然后告诉你 NTC / MOS 软启动怎么救。

  程序最后会回答两个具体问题：
  "为什么 10k + 100nF 做按键消抖刚好够用"（τ=1ms，
  过 2/3 阈值要 1.1ms，能吃掉典型的毫秒级短抖动；
  抖到 5~10ms 的烂开关，硬件 RC 只能减弱，还要软件采样确认）；
  "为什么长走线 + 一堆 100nF 上电会拉垮电源"
  （走线电阻 + 电容 ESR 极小 → 瞬时电流极大 →
  电源过流保护或者调压器压垮 → MCU 复位）。

**`voltage_divider_lab.html` ← 分压器交互实验台（离线，双击开）**

  重点：这是你的"玩具"。四个滑杆：Vin、R1、R2、RL（RL 可以选"空载"）。
  实时给你：SVG 电路示意图、空载理论值、带载实际值、误差百分比、
  分压电阻总功耗 + 推荐封装（0402/0603/0805/1206）。

  你要玩出感觉的三个动作：

  1. 把 R1 = R2 = 10k，然后从"空载"开始往下减 RL：
     1M → 100k → 10k → 1k → 100Ω。
     **看误差条什么时候变红。**
     规则很简单：**RL 和 R2 同数量级时，负载效应就不可忽略。**
     变红的那一行会给你一句师傅的骂。
  2. 把 R1、R2 都拉到 1M，负载设成"空载"，
     看看输出多"干净"——然后再看下面提示的戴维南内阻 = 500kΩ。
     **这 500k 会把你的 ADC 读数毁于无形**：
     ADC 内部采样电容要在 1µs 内充到目标值，
     500k × 10pF = 5µs，充不满，读数偏低且随输入历史漂移。
     这就是"datasheet 里那句 源阻抗 ≤ 50kΩ"是怎么来的。
  3. 点"一键推荐 10k 分压"按钮。
     它会告诉你为什么是 10k 而不是 1k 或 1M：
     **往下（1k）→ 功耗涨 100 倍、灌电流可能超过电源能力；
     往上（1M）→ 噪声敏感度涨、ADC 吃不下、PCB 表面漏电流开始有意义
     （潮湿的板子上，1MΩ 两端漏 10nA 就是 10mV）。**

**`rc_animator.html` ← RC 暂态交互动画（离线，双击开）**

  重点：滑块设 R、C、V0，实时画充电曲线和放电曲线，
  τ / 3τ / 5τ 处画竖线（63.2% / 95.0% / 99.3%）。

  最关键的一个交互是**"单步"按钮 + 电流表指针**。
  你每点一下，时间走一格，你会看到：
  - 电容电压条从 0 往上爬，越走越慢；
  - **电流表指针一开始猛打到头，然后迅速回落，最后归零。**

  这两条动画放一起看，你就终身记住了：
  **电容在接通瞬间等效短路（电流最大），
  充满之后等效开路（电流为 0）。
  所以"电容通交流、阻直流"不是口诀，是这两根指针的画面。**

  四个 preset 按钮，每个都对应一件真实的活：
  - `LED 上电延时`：100k + 100µF → τ = 10s，做"上电 10 秒后才允许继电器吸合"。
  - `按键消抖（5ms 窗口）`：10k + 100nF → τ = 1ms、5τ = 5ms，配施密特触发器。
  - `PWM 变 DAC`：1k + 10µF → τ = 10ms，PWM 周期 20µs（50kHz），
    τ/周期 = 500，平滑得住；
    把 C 换成 1nF（τ = 1µs），曲线立刻变成锯齿——
    **这就是"滤波电容选小了，输出是三角波不是直流"。**
  - `电源去耦`：看 100nF 在 1MHz / 10MHz / 100MHz 上的阻抗，
    和它自己的 ESL（约 1nH，0402 封装典型值）在 16MHz 附近的自谐振——
    **过了自谐振点，电容变成电感，阻抗开始往上走。**
    这是"为什么 100nF 和 10µF 要并联、
    为什么 0402 去耦电容比 0805 高频更好"的根。

## 五、学习建议与常见坑

师傅先说三条学习建议，再列十条坑。十条坑全是你以后会亲手踩的，
师傅已经替你踩过一遍了，你只需要"读一遍 + 在脑子里过一遍"。

### 学习建议

1. **先跑，再看，再改。** 每个文件都是先跑起来看到数字，
   然后读代码理解数字怎么来的，最后改参数自己预测结果再验证。
   顺序反了就是白看。
2. **手算一遍再让程序算。** `01_node_solver.c` 里的四组电路，
   你先在草稿纸上算，算完跟程序对。
   对不上，**恭喜，你找到一个真问题**，比程序对了十次都有价值。
3. **每算完一个数，先检查单位。**
   师傅带过的实习生里，把 100nF 写成 100µF 的、
   把 kΩ 当成 Ω 的、把 ms 当 s 的，
   一年里能凑一桌麻将。
   数量级错三位，是能"看起来对"的，
   所以只有单位检查能救你。

### 十条常见坑

**坑 1：忘了 GND 不是"地的绝对值"，它只是参考点。**
板子上有 GND、AGND、DGND、PGND，
它们之间可能隔着磁珠、0Ω 电阻、甚至只是一段细铜皮。
流 500mA 的返回电流经过一段 0.2Ω 的铜皮，
两端就差 100mV——
你的"模拟地"和"数字地"根本不是同一个 0V。
表现为：ADC 读数跟着负载电流一起抖。
**自查动作**：把万用表打到 mV 档（直流），
在板子运行时量任意两个"GND 点"之间的电压。不为 0，就找到问题现场了。

**坑 2：以为万用表量电压不影响电路。**
数字表 10MΩ 内阻听着很大，
但你量一个 10M/10M 的高阻分压（比如老式高压探头的分压网络），
并在上去就是并在 5MΩ 的等效负载，
输出直接从一半掉到 1/3。
**规则：被测量网络的等效源阻（戴维南内阻）超过 100kΩ，
就要开始怀疑读数；超过 1MΩ，读数基本是量你自己。**
指针式万用表（20kΩ/V）在 2.5V 档只有 50kΩ——
量 3.3V 的 10k/10k 分压，读数从 1.65V 掉到 1.50V（−9%）。

**坑 3：分压电阻取值忽视负载效应。**
这是本关的头号坑，占新手错误的半壁江山。
"我要 1.65V，3.3V 分一半，取 10k/10k，齐活。"
然后 ADC 读出来 1.2V。
为什么？因为 ADC 那一头的输入不是开路的
（要么内部采样电容在周期性地抽电荷，
要么你后面接了一个运放/比较器/三极管基极，它是有输入电流的）。
**自查动作**：算出分压网络的戴维南内阻 `Rth = R1·R2/(R1+R2)`
（10k/10k 就是 5k），
再看后级要抽多少电流。
**后级阻抗至少是 Rth 的 100 倍**，这个分压才算"没人打扰"。
做不到，就加一级运放跟随，或者干脆把 R1、R2 一起降下来。

**坑 4：电解电容的 ESR，以及"电容不是理想电容"。**
一颗 100µF/16V 的铝电解，ESR 可能有 1~2Ω，ESL 有十几 nH。
这意味着：
- 纹波电流 200mA 流过它，它自己两端就有 0.4V 的纹波，而且自己发热 0.08W；
- 在几百 kHz 以上，它的阻抗被 ESL 拉高，**去耦能力约等于 0**；
- 低温下（−20℃）电解的容量可能掉一半，ESR 涨几倍——
  冬天现场开机失败，实验室常温怎么都复现不出来。

  所以去耦网络是"10µF 钽/陶瓷 + 100nF + 1nF"并联，
  各管一段频段。
  还有极性：**铝电解焊反，会鼓包、漏液，运气不好会炸。**

**坑 5：上电冲击电流（inrush current）。**
你的板子上并了八个 100nF + 一个 100µF，
对 5V 电源来说，上电瞬间这坨就是一颗约 0.1mF 的空电容，
回路电阻只有走线电阻加 ESR。若回路是 1.5Ω（电解的典型 ESR），
峰值电流 = 5V / 1.5Ω ≈ 3.3A；若用一堆低 ESR 陶瓷把回路压到 0.2Ω，
就是 25A。电源要么进限流/打嗝保护，要么输出瞬间塌到 2V，
MCU 的 POR（上电复位）阈值没满足，
表现就是"插上电源要按两下复位键才能起来"。
**解法**：NTC 热敏电阻限流（冷态几欧，热态几十毫欧）、
MOS 软启动、或者分级上电。
`02_rc_transient.c` 里会把这个数字算给你看。

**坑 6：把电流源当电压源接（或反过来）。**
理想电压源不能短路（电流无穷），
理想电流源不能开路（电压无穷）。
实际设备里，LED 驱动很多是**电流源输出**，
你在它输出的两端短接，它不会坏，但你量到 0V 会误判"没输出"；
反过来，你把一个电流源的输出悬空（断线、焊点虚焊），
它会把输出电压一路顶到它的合规电压上限（compliance，可能几十伏），
烧掉后面接的一切。
**现场表现**：LED 灯带某一段的接线端子松了，
那一段不亮，同时那个驱动芯片发热严重或者烧了。
**军规：接任何"驱动类"输出之前，先搞清楚它是电压输出还是电流输出。**

**坑 7：LED 不限流。**
LED 是电流器件，端电压和电流之间是指数关系。
一个 3.3V 的 GPIO 直接怼一颗蓝色 LED（ Vf ≈ 3.0V @ 20mA ），
Vf 只要比"电源电压"低 0.3V，电流就是电源输出阻抗和线路电阻在决定——
可能 100mA 以上。
**GPIO 的驱动能力一般是 8~20mA，绝对最大值 25mA，超了要么烧引脚，
要么 MCU 那一路的电源被拉挂。**
限流电阻永远不能省。
至于"我这条线走了 30A 所以不用电阻"——那是恒流驱动芯片的事，不是 GPIO 的事。

**坑 8：把 0Ω 电阻当摆设删掉。**
0Ω 电阻在板子上有六七个正经用途：
- **跳线/选件**：同一块板子跳 3.3V 或 5V，焊哪个位置定；
- **单点连接**：模拟地和数字地之间放一颗 0Ω 或磁珠，把返回电流约束到一个点，
  你以后测噪声就靠它——**把它短接成一大片铜，噪声耦合路径就回来了**；
- **测试点**：把某段供电断开，串一个电流表实测功耗，
  这是量产前测待机电流的标准做法；
- **预留 DNP**（Do Not Place）：设计时不确定要不要这个电阻，
  焊盘留着，元件不贴，改板时不用重画；
- **走线绕行**：在密排 BGA 底下，0Ω 可以当"跨线桥"；
- **匹配/校准位**：射频前端的 π 型匹配网络，
  0Ω 是"这一路直通"的意思。

  **你把 0Ω 删了，板子当天是好的，改天就出问题，且没人知道为什么。**

**坑 9：忽略磁珠不是电阻、也不是电感。**
磁珠的规格写"600Ω @ 100MHz"——
这是**在 100MHz 时的阻抗（Z）**，不是电阻。
在 1MHz 时它可能只有 15Ω，在 1GHz 时可能又掉回去了。
而且磁珠有额定电流和**直流电阻 DCR**：
"600Ω@100MHz / 2A" 的磁珠，DCR 常见 0.1~0.3Ω，
流过 500mA 就压降 0.15V、发热 0.075W；
流 2A 的时候它压降 0.5V，
**你后面接的是一个 3.3V 的模块，此时它只有 2.8V，
卡在最低工作电压边缘——实验室常温好用，机箱里温度高一点就随机重启。**

  还有一条：磁珠是**损耗型**的，
  它把高频能量变成热；电感是**储能型**的，
  会和谐振。磁珠后面直接接大容值电容，
  某些情况下会形成一个 Q 很高的谐振，
  上电瞬间磁珠后面能出现**过冲电压**（比输入电压还高），
  把后级耐压 6V 的器件打到 9V。
   datasheet 里那句"磁珠后建议并联一个 100Ω~1kΩ 的阻尼电阻"就是这个意思。

**坑 10：以为电阻没有寄生、导线没有电阻。**
一颗 0402 的 10kΩ 电阻，寄生电感大约 0.4nH，寄生电容约 0.3pF。
低频无所谓，2.4GHz 就不无所谓了。
一条 10cm 的杜邦线，电阻约 40mΩ，电感约 300nH——
300nH 在 10MHz 时阻抗是 19Ω！
**"我用杜邦线接了一个 10MHz 的 SPI，读不到数据"——
不是信号质量问题，是那条线的电感加了 19Ω 的串联阻抗，
边沿被拉成了梯形。**
还有 PCB 走线：1oz 铜、10mil 宽，每英寸约 0.5mΩ 和 8nH。
**你以后看到"高频"两个字，第一件事是把所有"理想导线"重新画成电阻+电感。**

### 额外三条：算错了怎么办

- **算完先看数量级。** 电流是 µA、mA 还是 A？
  功率是 µW、mW 还是 W？数量级对了，再纠结第三位数字。
- **拿特殊值代入验算。** 负载短路、负载开路、R1=0、R1=∞，
  结果应该退化到你一眼能看出的样子。
  如果算出来"负载短路时输出电压还有一半"，那公式一定写错了。
- **量一个能验证它的东西。**
  算出 LED 电流 8.8mA，就把万用表串进去量。
  **量出来对不对，比你想一百遍都有用。**

## 六、老师傅的家庭作业（5 道，全是动手题）

不许查公式直接给结论，必须"做 → 记录 → 对照理论"。
每道题都准备一个本子，把数字写下来。

**作业 1：量你自己手机充电器的空载电压，并且发现它"不准"。**
- 万用表直流 20V 档，红黑表笔插到 USB-A 的 VBUS 和 GND 上（或者剥一根废线），
  记录空载电压。
- 再插上一个正在耗电的设备（手机充电中），再量一次。
- **报告要求**：两次读数各是多少？差了多少？
  为什么充电器空载时可能是 5.15V，接上负载变成 5.02V？
  （提示：这不是"电池不准"，这是调压环路的负载调整率 +
  线缆电阻压降。再算一下：0.08V 的差，如果是 0.08Ω 的线缆电阻造成的，
  电流是多少？）
- **加餐**：把表笔换成另一根数据线再量一次，比较两根线的差别。

**作业 2：亲手做负载效应实验，把本关最值钱的那张表量出来。**
- 找两颗相同阻值的电阻（比如两颗 10k，实在没有用 1k 也行），串在 5V 和 GND 之间。
- 先量中点对 GND 的电压，应该 ≈ 空载理论值的一半。
- 然后依次并在输出端一颗电阻：10k、1k、100Ω（用你手头有的最接近的）。
- **报告要求**：把"空载 / 挂 10k / 挂 1k / 挂 100Ω"四个读数列表，
  再按 `V = Vin · (R2∥RL) / (R1 + R2∥RL)` 算出理论值，逐行对照。
  误差 5% 以内算过。
- **师傅会问**：量挂 100Ω 那次的时候，你的电阻烫不烫？
  注意别掉坑：100Ω 一挂上去，输出已经被拉塌到约 0.03V，
  它两端不是 2.5V，实际功耗只有约 10µW——根本不烫。
  要是你算出 62.5mW，说明你还在用"空载 2.5V"算带载功耗，
  这正是本关要治的负载效应。

**作业 3：给"上电延时"选一颗电容，然后把它拆下来量。**
- 用一颗 10kΩ（或你手头最接近的）串一颗电解电容（47µF 或 100µF）到 GND，
  中间点接一个 LED + 限流电阻（可选，用来看趋势）。
- 5V 上电，用万用表每隔 1 秒读一次中点电压，读 15 次，画在坐标纸上。
- **报告要求**：算理论 τ = R×C，
  从你的数据里"拟合"出实测 τ（电压到 63.2% 的时刻），
  比较两者差多少。
  电解电容的容差是 ±20%，你的实测落在这个范围内吗？
  **顺手量一下那颗 10k 电阻实际是多少**（万用表电阻档），
  贴片电阻一般是 ±1%——你会发现电阻比电容准得多，
  这就是为什么定时的精度要靠电阻、靠电容就只能"大概"。

**作业 4：抓出你自己板子（或任何一块手边的电路板）的"地不是同一个地"。**
- 板子**通电运行**时，万用表 mV 档，
  黑表笔固定在主 GND 焊盘（比如 USB 屏蔽壳、或者晶振外壳），
  红表笔依次点：MCU 的 GND 引脚、某颗去耦电容的 GND 端、
  传感器接口的 GND 针、另一个"GND 过孔"。
- **报告要求**：记下每一对之间的电压（mV），
  挑出差值最大的那一对，在板子上追出这两个点之间的铜皮路径，
  估算这段铜皮的电阻（1oz 铜、10mil 走线，每英寸约 0.5mΩ），
  再估这段路径上流过多大电流（P/V 反推）。
  两者乘积，跟你量到的 mV 对得上吗？

**作业 5：把 PWM 变成 DAC，然后用示波器（或没有示波器就用万用表）验。**
- MCU（Arduino / ESP32 / 任意有 PWM 的板子）输出一路 50% 占空比的 PWM，
  串 1kΩ，对地接 10µF，取电容上的电压。
- 万用表量这个电压：应该是电源电压的一半（±几十 mV）。
- **报告要求**：
  ① 算 PWM 频率、τ = RC，说明为什么 τ 必须远大于 PWM 周期；
  ② 把 10µF 换成 100nF，再用万用表量一次——
  读数会掉下来并且不稳，为什么？（用 `rc_animator.html` 的
  `PWM 变 DAC` preset 把 C 调小，看曲线变成锯齿，就明白了）；
  ③ 有示波器的话，量两种情况下的纹波峰峰值，记录下来。

  **交作业形式**：一页纸，
  五个小表 + 每道题一句"我错了什么"。
  错，是正常的；写"全部符合理论"的，师傅要重查。

```
欧姆定律         V = I · R
```
