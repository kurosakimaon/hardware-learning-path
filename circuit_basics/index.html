第 1 关 · 筑基期

电路基础：电压是两点之差，电流是一个回路

这一关不讲玄学。你只需要把四件事刻进骨头里： 电压永远是两点之间的、电流必须有回路才存在、 任何电源都有内阻、你算出的理想值，接上负载之后一律作废。 后面五关——模电、MCU、PCB、仪器、做板子——全部建立在这四句上。

本关文件清单

六个文件，两个 C 程序是师傅算给你看的，两个 HTML 是你自己上手拖的。全部离线，双击即开。

学习顺序建议

总共约 4~6 小时。别跳步，每一步都依赖上一步建立的感觉。

  1. 读 tutorial.md 第一、二章（约 20 分钟）。只看"师傅为什么先让你焊 LED"和 "电流直觉五条"。目标是在脑子里建立一个画面：电荷在回路里跑，跑多快由总电阻决定， 而不是由某一点决定。
  2. 打开 voltage_divider_lab.html，先什么都不动。 看空载那一屏：纸面值 = 带载真值，误差 0.00%。 然后取消勾选"视为空载"，把 RL 从 10MΩ 一路往左拖。 你会看到误差从 0.005% 一路涨到 98%。在这个页面上待够 15 分钟， 直到你能不看数字就预判"现在大概是 1.1V 左右"。
  3. 编译 01_node_solver.c，对照输出读代码。 先在 main() 里找到四个演示函数，跑一遍看结果； 再回头读 buildStamp() 旁边的注释， 理解"每个节点写一条 KCL，每条支路用电流 = 电压差 / 电阻"是怎么变成矩阵的。 编译命令（PowerShell，在本目录下）：
# 需要 MSYS2 / MinGW 的 gcc（本项目在 gcc 16.2 + Windows 下验证，零警告）
chcp 65001   # 运行/编译前先把终端切到 UTF-8，否则中文输出会乱码
gcc -std=c17 -O2 -Wall -Wextra 01_node_solver.c -o 01_node_solver.exe
.\01_node_solver.exe

# 同理
gcc -std=c17 -O2 -Wall -Wextra 02_rc_transient.c -o 02_rc_transient.exe
.\02_rc_transient.exe
  1. 自己改网表。把 LED 那组的 330Ω 改成 100Ω，看电阻功耗从 24.5 mW 涨到多少，再对照封装表（0402 = 1/16W）判断它会不会烤。 把电桥的一个 10k 改成 10.1k，看输出从 0 A 变成毫伏级—— 这一刻你就懂"为什么需要仪表放大器"。
  2. 打开 rc_animator.html，按 preset ②（按键消抖）。 按"单步"，一格一格看：电压涨多少、电流掉多少、两者之和恒等于 V0（这就是 KVL）。 然后把 R 拖到 10Ω 看电流表指针死死顶住——那就是上电冲击。
  3. 编译 02_rc_transient.c，重点看三张表： 欧拉误差表（dt=τ/10 误差 1.92%、dt=τ/100 误差 0.185%）、 R/C 扫描表（10k+100nF → τ=1ms、tr=2.197ms、fc=159.2Hz）、 冲击电流表（5mΩ 回路 → 理论 1000A）。
  4. 做 tutorial.md 第六章的五道家庭作业，全部要动手： 万用表量手机充电器空载电压、算自己板子的待机电流、 给一个 12V→3.3V 场景选分压电阻并说明为什么不这么干。
  5. 对着"通关标准"逐条打勾（见下方自检表）。有一条打不上勾就回去补， 不要带着缺口进第 2 关——模电会把这里的每个漏洞放大十倍。

常见坑（本关最高频的十条，完整十条在 tutorial.md 第五章）

下面每条都是真实发生过的返工，不是编出来吓人的。红色是"会烧东西或量错一整天"的，黄色是"精度和余量上的暗亏"。

① LED 不限流直接接电源 LED 是电流器件，它的伏安曲线在导通后陡得像根线。5V → LED 不上电阻， 电流由曲线自己决定，几百 mA 起步，几百毫秒内灯珠发黑。 永远用 R = (V源 − V_LED) / I目标。
② 分压输出直接接 ADC / 下一级 10k+10k 空载 1.650V，挂上 10k 负载只剩 1.100V。 纸面公式忽略了一个事实：R2 和负载是并联的。 卡死判据：后级阻抗 ≥ 100 × Rth（Rth = R1∥R2）。
③ 拿万用表当理想电压表 表笔内阻典型 10MΩ。量 1M/1M 分压点（Rth=500kΩ），表笔直接把电压拉低 ~4.8%； 量 10MΩ 以上的节点，读数基本是表笔决定的。高阻节点要用跟随器或 x10 探头的正确设置。
④ 以为 GND 是"绝对 0V" GND 只是你选的参考点。电流流过地线阻抗就产生压降， 数字地回流路径上的 50mA × 0.1Ω = 5mV 看起来不大， 但你的 1mV 级传感器信号就泡在这片泥里。
⑤ 把 τ = RC 当"充满时间" 1τ 只有 63.2%，3τ 只有 95.0%，5τ 才是 99.3%。 12 位 ADC 要 0.5LSB（0.012%）至少要 9τ，工程上留余量按 10~11τ。 延时电路按 5τ 设计，采样保持按精度反推。
⑥ 上电忽略冲击电流 I(0) = VCC / 回路总电阻。板子上并了一堆电解，回路只有几十毫欧时， 理论峰值上百安。真实波形是窄尖峰，但它足够让电源打嗝、USB 跳闸、开关触点烧蚀。 大电容输入必须上 NTC 或 MOS 缓启动。
⑦ 去耦电容离芯片 10cm 去耦的敌人是电感不是电容。走线约 1nH/mm， 30cm 排线 ≈ 300nH，和 100nF 谐振在 919kHz—— 加电容反而辐射超标。必须每脚一颗、紧挨着放、回路面积最小。
⑧ 用电流源当电压源用 理想电流源两端电压由负载决定，开路时会飞到天上去。 反过来把电压源当电流源（比如"12V 直接接 20mA LED"，靠内阻限流）也一样翻车。
⑨ 0Ω 电阻和磁珠当成"没用" 0Ω 电阻用来跳线、单点接地、预留调试点、焊盘兼容不同封装； 磁珠在高频呈现阻抗，用来吸收高频纹波—— 它不是小电阻，别拿它当大电流电源线，几 A 的直流路径上放磁珠会自己烧掉。
⑩ 电阻只看阻值不看功率和封装 0402 是 1/16W，0603 是 1/10W，0805 是 1/8W，1206 是 1/4W。 分压算出 150mW 还选 0402，板子跑两小时焊点就虚了。 按最大那颗选封装，并留 50% 降额。

解释为什么 10k + 100nF 做消抖"刚好" τ = 1ms，5τ = 5ms 盖住 1~5ms 的机械弹跳；330µA 省电、10k 不引噪声 □
