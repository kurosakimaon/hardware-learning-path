第 4 关 · 兵器期

MCU 与嵌入式

HAL 是组装好的成枪，寄存器是枪膛里每一发子弹的上膛方式。这一关先把兵器拆着看： GPIO 位域（BSRR 为什么存在、ODR 怎么抹掉别人的引脚）、 UART 时序（BRR 怎么算、±2% 误差预算从哪来）、 I2C 总线（上拉电阻区间、死锁与 9 脉冲恢复）、 调度与中断（最坏延迟怎么算、ISR 忙等怎么饿死低优先级、看门狗怎么配才算配）。 9 个文件全部离线：4 个 .c 用软件模型模拟寄存器、无硬件编译即跑，3 个 HTML 双击即开。

🪜 学习顺序（别乱）

  1. 读地图：通读 tutorial.md，记住四句：改输出只用 BSRR；误差是链路总和；上拉是区间不是定值；ISR 的字数要像省电一样省。
  2. 玩寄存器：编译跑 01_gpio_registers.c，对锚点数字（复位值 0xA8000000、四配置后 MODER=A8085400、竞态 0x28 vs 0xA8），再打开 register_playground.html 按一遍"错误示范"。
  3. 算波特率：跑 02_uart_timing.c，用手复算 72M→0x271 和 8M→0x045 两笔账；然后打开 uart_frame_animator.html 把偏差推到刚好帧错误（±2.7% 附近），和 ±5.26% 公式对上。
  4. 玩总线：跑 03_i2c_bus.c，重点看 300ns/1000pF 那组"区间为空"的死局和 9 脉冲恢复逐拍过程；把恢复逻辑抄进你自己的驱动模板。
  5. 看调度：跑 04_scheduler_irq.c，五个演示按顺序读输出：先算 40µs 最坏延迟的三项构成，再看饿死→复位实录，最后用 IWDG 表反推你自己项目的狗档位。
  6. 过时钟：打开 clock_tree.html，四个预设挨个点，把每条红色告警的"为什么"说给自己听；然后关掉预设，自己凑一个 HSE 8MHz 下 CPU 最高、USB 能用的配置。
  7. 交作业：做 tutorial.md【七】的 5 道作业（后附答案要点），毕业自测是【八】通关标准的六条勾选框。

🕳️ 本关高频坑（完整 13 条在 tutorial.md）

ODR 读改写抹别人引脚ODR |= 1<<3 是三步操作，中断插进缝隙就丢位。带中断的系统改输出只准用 BSRR，0x28 那次就是证据。
EXTI 忘清挂起位PR 位是硬件电铃，不敲掉就退出即重进——中断风暴 + 主循环饿死 + 狗复位，三件套连环迷惑。
ISR 里忙等/浮点 printfISR 忙等 5ms 而周期 1ms：返回当拍二次进入，TIM 连占 99ms，喂狗 0 次。ISR 只置标志 + 搬字节，重活进延迟队列。
HSE 死等 HSERDYwhile(!(CR&HSERDY)); 晶振虚焊就永远卡这。必须带超时退 HSI，"上电没反应"有一半是这么来的。
APB1 忘 ÷272MHz 灌进 36MHz 域，串口 2 偶发乱码、I2C 高温 NACK——超频初期九次半是对的，就那半次要命。
I2C 上拉"经验值 4.7k"打天下升 400kHz（tr≤300ns）就原形毕露。Rmin=Vdd/3mA、Rmax=tr/0.847Cb，区间为空就降容性降速率。
看门狗无条件喂主循环开头一句喂狗=装了个从不响的火警。按心跳喂：关键任务全置位才喂，卡死立刻断喂。
SWD 引脚被固件复用后"变砖"BOOT0 拉高进 System Memory 擦固件是唯一后悔药——板子上 BOOT0 测试点必须留。

🎯 通关暗号（师傅抽查就抽这几个数）

72MHz→115200：BRR=0x271 误差 0.00% · 8N1 采样极限 ±5.26%，工程预算 ±2% · 3.3V/150pF 上拉 1.1k~7.9kΩ · IWDG 超时=预分频×(重装值+1)÷40kHz，LSI 30~60kHz · 最坏中断延迟=临界区剩余+上级尾巴+入栈 · APB1≤36 / APB2≤72 / ADC≤14 / USB=48。 三句口诀：改输出只用 BSRR；误差是链路所有环节的总和；ISR 里睡一觉，系统里死一片。
