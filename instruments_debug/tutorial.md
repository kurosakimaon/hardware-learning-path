# 第 6 关：望闻问切 · 仪器与排障心法

老师傅带你从零开始，一步一个脚印

## 一、模块简介：师傅为什么先让你"把示波器校准一遍再碰板子"

徒弟，把你手里的板子放下。先把手洗了——别笑，
手指头上的汗渍就是后面焊盘起皮的头号帮凶，这事后面再说。

你上周借了块板子回来，急吼吼地拿烙铁就怼上去改电阻，
结果板子从"偶尔复位"变成"彻底躺平"。师傅今天把话撂这儿：
**你不是不会修板子，你是连"尺子准不准"都没确认就开量了。**

仪器是硬件工程师的听诊器和手术刀。
万用表、示波器、逻辑分析仪、电源、电子负载、频谱仪、近场探头——
每一样你都得知道它"能量什么、不能量什么、什么情况下会骗你"。
仪器骗人的方式五花八门：

- 示波器采样率不够，给你画一条**稳定得可疑的正弦**，
  频率是假的，你还夸"这信号真干净"；
- 探头放在 ×1 档去量 10MHz，100pF 输入电容往上一搭，
  信号直接被你自己吃掉了大半，你以为电路坏了；
- 鳄鱼夹地线拖了 15 公分，约 150nH 的电感和 ×10 探头的 10pF 电容
  谐振在约 130MHz（×1 档 100pF 时约 41MHz），你量到"满屏振铃"，
  其实振铃是你自己夹出来的；
- 万用表电阻档去量带电的节点，表笔一搭"啪"一声，
  表里那根 200mA 保险跟你永别了——这还是轻的，
  电流档并到电压源上，那叫"炸表现场"；
- 逻辑分析仪阈值设成 2.5V 去量 1.8V 的 I2C，
  读出来全 0，你换了三块传感器，最后发现是阈值的事。

所以这一关，师傅不教你背仪器参数表，
师傅教你三件事：

1. **仪器的物理模型**：带宽、采样率、存储深度、垂直位数、
   输入阻抗、精度指标，它们各自管什么、怎么互相打架；
2. **探头的学问**：×1/×10、负载效应、接地弹夹、
   为什么"探头是电路的一部分"而不是"一根线"；
3. **排障方法论**：拿到一块陌生板子或者坏板子，
   怎么按"先目视、再断电量阻、再上电量压、再注入信号"的顺序，
   用二分法和故障树把问题缩到"某个器件某个引脚"，
   而不是瞎猜瞎换、换到怀疑人生。

"望闻问切"四个字就是本关纲领：
望——目视，先看烧毁痕迹、电容鼓包、虚焊裂纹；
闻——鼻子闻，焦味是最便宜的故障诊断仪；
问——问使用者：什么时候坏的、干了什么、天气如何；
切——上手量，但要按章法量，每一步都在缩小包围圈。

这一关 8 个文件：3 个 C（C17）可运行示例（示波器建模、测量误差链路、
排障模拟器）+ 3 个离线交互动画（采样混叠、探头负载、排障决策树）
+ 课本 + 导航页。全部不用联网，双击、gcc 就能跑。

## 二、为什么排障是一门方法论，而不是运气

很多人觉得老师傅修板子"神"：一摸一量，三分钟定位。
你以为是手感，其实是他**每一步都在做选择题，而且每个选项都值钱**。

排障的本质是一个**信息论问题**：
故障是未知的，你的每个测量动作都有代价（时间、拆焊风险、烧板风险），
聪明的策略是"花最小代价，问出最能劈开候选故障集的那个问题"。

不信？本关的 `03_debug_bisection.c` 给你算得明明白白：
一块 5 路电源的板子注入 6 种故障之一，
贪心故障树策略平均 2~4 步锁定，8 步封顶；
"随机乱测"策略平均要翻一倍还多。
**系统化排障不是玄学，是省一半时间的算术。**

再看"重启就好了"这五个字。师傅年轻时也爱说，
后来明白：**重启不是修复，是把证据销毁了。**
偶发复位你重启十次好了，客户现场一天复现八次。
重启掩盖的从来不是小问题：电源跌落裕量不足、复位线耦合、
晶振边际振荡、过温保护——每一个都等着在量产爆发。
排障的第一美德是让故障**可复现**，第二才是修。

还有上电冒烟这种事。冒烟不是结束，是仪式的开始：
**立刻断电，别拍照，先断电。**
然后断电量输入电阻、量各轨对地电阻，找到低阻的那一路，
查清楚是器件击穿还是电容短路，修完先用电源限流 10mA 上电，
看电流曲线正常再逐步放开。直接怼回电源"再看一次冒烟"的，
师傅见过太多，那块板子本来只烧一个 MOS。

这些东西，背是背不会的。得在你手上过一遍。

## 三、学习目标

学完本模块，你要能做到（每条都可自检）：

1. **能根据被测信号的上升时间选出示波器带宽与采样率**：
   给一个 100MHz、tr=2ns 的时钟，说出为什么带宽至少要 500MHz
   （5×f 主导；0.35/tr 只给出 175MHz）、实时采样为什么要 ≥5 倍带宽、
   存储深度不够为什么波形被"降采样"
2. **能解释"带宽够但采样率不够会看到假波形"**：
   徒手算出 1MHz 信号用 1.1MSPS 采样的混叠频率（100kHz），
   并说清等效时间采样为什么能看高速信号却抓不了单次事件
3. **能根据被测电路选探头并估算负载误差**：
   量 1MΩ 分压点，说出 ×1 档误差多大、×10 档误差多大、
   长鳄鱼夹地线把振铃 Q 值抬到多少
4. **能用不超过 8 步定位一块 5 路电源板哪一路挂了**，
   并说清每一步"排除了哪些假设、还剩哪些候选"
5. **能读懂万用表精度指标并算出测量不确定度**：
   "±(0.05% rdg + 2 digits)"在 2V 档量 1.5V 是 ±多少 mV，
   合成不确定度怎么把仪器项和重复性项平方和开根号合起来
6. **能设计一次安全的上电流程**：限流值怎么定、
   先量哪几个电阻、冒烟之后前三步做什么
7. **能完成一次不出事故的返修**：说出热风枪温度/风量/时间的
   合理区间，以及为什么在 0402 旁边吹 1206 必须贴 kapton 胶带

## 五、学习建议与常见坑

学习建议先说三条：

- 每啃完一个文件，**回到现实**：手边有仪器就拿真信号对一遍，
  没有就把动画里的数字手算一遍，别让它停在"看懂了"；
- 建一个"测量事故本"，记录每一次"量出来的和预期不符"，
  三个月后它比任何书都值钱；
- 排障永远先问三个问题：什么时候坏的？当时干了什么？
  环境有没有变（温度/湿度/供电/搬动过）？
  这三问免费，且一半的故障答案就在里面。

然后是坑。十三条，每一个师傅都亲自踩过或看着别人踩过：

1. **探头放 ×1 档去量高速/高阻节点**。×1 档输入电容 100pF 上下，
   量 10MHz、源阻抗几 kΩ 的节点，信号先被你自己低通滤波一半。
   规矩：除非量低频大功率或需要最高灵敏度，默认挂 ×10。
2. **只用长鳄鱼夹地线，然后被"满屏振铃"骗了**。15cm 地线约 150nH，
   和 ×10 探头的 10pF 电容谐振在约 130MHz（×1 档 100pF 时约 41MHz），
   方沿一激就振。
   量开关类节点务必用弹簧地短弹夹，或者干脆把鳄鱼夹换下来。
   **振铃变大，先怀疑你的地线，再怀疑别人的电路。**
3. **示波器通道耦合与输入阻抗误设**。上一位同事把通道设成 50Ω
   输入没改回来，你拿 1MΩ 探头去量 12V，示波器输入直接趴下；
   或者 AC 耦合把纹波测量中的直流偏置抹了，你以为电源漂移了。
   每次开机先检查：耦合 DC/AC、输入 1M/50Ω、探头衰减比。
4. **采样率不足看到"稳定的假波形"**。混叠出来的假频率是确定的，
   所以它稳定得不像话。看到"频率刚好是你采样率整数倍差值"的
   信号，先抬采样率再下结论。本关动画 preset 二就是现场演示。
5. **存储深度不够，波形被仪器偷偷降采样**。1M 点的机器设 100ms
   时基，采样率自动掉到 10MSPS，毛刺全被平均没了。
   抓单次毛刺：短窗口 + 最大采样率 + 最大存储深度，缺一不可。
6. **用电阻挡量带电节点**。电阻档是表自己输出电流测压降的，
   节点一带电，读数离谱是小事，进大电流烧档是常事。
   口诀：**测电阻，先断电，等电容放完**。
7. **电流档并到电压源上**。万用表电流档内阻milli欧级，
   并联到电源两端等于短路，保险丝（甚至表笔）就是牺牲品。
   电流必须**串**进回路；表笔插孔也要记得换（COM + A/mA 孔）。
   小电流优先用"量串联采样电阻上的压降"的旁路办法。
8. **逻辑分析仪阈值设错**。1.8V 的系统设 2.5V 阈值，
   全读 0；或者把 I2C 当 UART 解码，采样点全错读出一堆乱码。
   接 LA 前先查该电平标准的 VIH/VIL，阈值取中点附近，
   协议解码器也要和实际参数（波特率/时钟方向/采样沿）对上。
9. **频谱仪 RBW/VBW 设错，对着噪声底判 CISPR 限值**。
   准峰值测量里 RBW 必须是标准规定的 9kHz/120kHz 档，
   RBW 设大了噪声底抬高、设小了扫描到天荒地老，
   VBW ≥ 3×RBW 才能读到真峰值。测量前先看标准怎么说。
10. **只量电压不看电流**。电压是"果"，电流才是"因"：
    LDO 输出 0V，是短路拉低还是使能没开？量一下输入电流，
    0.00A 直接排除短路假设。电源问题不量电流，等于医生只看不摸。
11. **"重启就好了"**。重启是销毁证据。偶发问题第一步是
    **建立复现**（老化、温循、加监视打印、电源串电流探头
    单次触发蹲守），复现不了不下结论，修完要能解释因果。
12. **热风枪温度时间乱设，焊盘起皮/吹飞小件**。铅-free 工艺
    350°C 上下、风量够用即可、对着一个位置吹超过 20 秒就该停手
    冷却再来。0402 旁边的焊盘薄，起皮往往是一瞬间的事；
    旁边的小元件贴 kapton 胶带或用铝箔挡住。
    **起皮的焊盘救回来的代价是报废的十倍。**
13. **探头补偿忘了做**。10:1 探头不补偿，测出来的边沿时间
    和过冲全是探头的形状。每台示波器旁边都贴着方波校准端子，
    换探头必补偿——这就是师傅让你先校准再碰板子的原因。

## 六、家庭作业（5 道动手题）

别写纸面答案，全要动手，答案以你量到的数字为准：

**作业 1：给自家（或借来的）示波器做一次"体检"**
用机内方波校准端子做探头补偿；然后设 1MSPS 采样率，
发生器（或 MCU GPIO 翻的 200kHz 方波）打进去，
逐步抬采样率，记录"假频率"消失的那一档；
对照 f_alias 公式验证你观察到的假象频率。

**作业 2：量自己板子的上电时序**
用单次触发（上升沿，设在 5V 轨）抓一次冷上电，
把每一路电源从 0 爬到稳态的时间都标出来，
对照主芯片 datasheet 的 power sequencing 要求，
写清楚"哪一路必须先起来、间隔要求多少、你的板子裕量多少"。
没有示波器：找同事/同学借，或用手机慢动作拍 LED 起电顺序
做个粗糙版，再说明为什么电压法更可信。

**作业 3：复现一次"假振铃"**
找一个开关节点（DCDC、MOS 驱动都行），
先用 15cm 鳄鱼夹地线量一遍，存波形；
再换 5mm 弹簧地（或最短接地弹片）量同一位置；
两张图并排放，标出各自的振铃幅度和振铃频率，
用 f = 1/(2π√(LC)) 反推你"夹"出来的回路电感，看是不是
约 1µH/m（1nH/mm）量级。做完你会终身记住这一条。

**作业 4：万用表负载误差实测**
找两个等值大电阻（100kΩ 以上）搭个分压器，理论中点是输入的一半。
分别用你手头万用表量中点电压，再量"表笔并上去之前"用电阻档
算出的理论值（断电算），算出负载误差百分比；
然后换 ×10 探头挂示波器量同一个点，对比两者误差，
解释为什么电阻越大误差越大（提示：Thevenin 输出阻抗）。

**作业 5：给一块"坏板子"写排障剧本**
任选 debug_tree.html 里没走过的一条链路，
走完并截图；然后在你自己的某块真板子上

## 七、通关标准

对照检查，全部打勾才算过关：

- [ ] 3 个 C 示例编译零警告、跑通，并能**用自己的话**解释
      输出里每个关键数字（混叠频率、负载误差百分比、平均排障步数）
- [ ] 3 个动画的所有 preset 都点过，且每个能说出
      "这个现象背后的那条公式"（混叠公式 / 谐振公式 / 信息增益）
- [ ] 纸面题：给"100MHz 时钟、tr=1ns、幅度 800mV"的信号，
      5 分钟内写出建议带宽、实时采样率、存储深度、垂直档位，
      并各给一句理由
- [ ] 作业 1~3 有波形照片/截图存档；作业 5 的排障剧本
      步骤数 ≤8 且每步都写明了"排除了什么"

- [ ] 能说出热风枪返修的三要素（温度、风量、时间）各控制在

## 附：师傅的工具箱（进关前点一遍名）

不用一步到位配齐，但下面每一样你都得知道它是干嘛的、
什么时候必须用它。缺哪样，对应作业就想办法借。

**测量类**

- 数字万用表：6000 counts 起步（3½ 位只能完成一半作业），
  二极管档、通断蜂鸣必须有。电流档保险丝常备两根——真的会烧。
- 示波器：带宽 ≥100MHz、实时采样 ≥1GSa/s、有单次触发。
  二手泰克/是德的老机型两三千就够本关全部作业。
- 探头配件：**接地弹簧弹夹**（本关最重要的一件，几十块钱
  救你无数次）、探头补偿螺丝刀、BNC 转鳄鱼夹短线。
- 逻辑分析仪：8 通道 24MHz 的入门款即可，跑 UART/I2C/SPI 解码。

**供电与焊接类**

- 可调直流稳压电源：带**限流旋钮**且限流值能设到几十 mA，
  上电试探、短路排查全靠它。不会限流的电源等于没有保险。
- 热风枪 + 助焊剂 + 吸锡带 + kapton 胶带：返修四件套。
  温度 350°C 上下、时间 20 秒以内是分寸线。
- 松香酒精溶液（松香:无水乙醇 ≈ 1:3）：涂在疑似短路的
  区域再灌限流电流，先熔的元件就是热点——穷人版热成像。

**辅助类**

- 信号发生器，或者一段能翻 GPIO 的 MCU 小程序（本关够用）。
- 毫欧级采样电阻几颗（0.1Ω/1Ω）："量压降算电流"的旁路方案，
  比万用表电流档安全得多。
- 一个纸质或 markdown 的"测量事故本"：每次"量出来不对"
  都记一行——现象、猜测、真相。三个月后回看，
  它就是你自己的《坑谱》第二卷。

配不齐也别停在"等装备"上。本关 3 个 C 和 3 个动画
**一台电脑就能全部跑完**，先把"为什么"想明白，
再拿真仪器把"果然如此"量出来——顺序别反。
