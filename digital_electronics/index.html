第 3 关 · 结丹期

数字电路：0 和 1 之间，藏着你必须算的每一个纳秒

你以为数字电路把连续的复杂度关进了笼子里。这一关师傅要告诉你： 它只是被藏起来了，没有被消灭。 电平是电压区间不是电压值、混合电压会倒灌烧脚、开漏不接上拉就是根天线、 计数器进位打穿四位会吐出一根 13ns 的毛刺、保持裕量为负时降频一点用都没有。 这一关的四件事：电平家族、组合逻辑化简、时序与毛刺、 建立/保持时间与亚稳态，最后用表驱动状态机把它们组织成能交付的东西。

本关文件清单

八个文件：一份主课本、四个 C17 程序（全部软件层面的逻辑仿真器 / 周期精确模型， 不联网、不读文件、不依赖任何真实硬件）、两个交互动画。 纯 C（C17），MSYS2 gcc 16.2 下 -std=c17 -O2 -Wall -Wextra 零警告。 HTML 全部离线单文件，断网双击即开。

FILE 01 · 主课本
tutorial.md读物
师傅嘴正文：为什么入门仪式是拿 74HC00 搭环形振荡器、 电平四参数与噪声容限、3.3V/5V 混接为什么会烧、open-drain 的取值妥协、 7 条可检验学习目标、逐文件的学习重点与预期数字、 11 条真实坑、5 道动手作业、通关清单、公式速查。
学习重点：先通读第一、二节再碰任何代码。 核心一句：0 和 1 是电压区间，不是电压值。
FILE 02 · C17 · ★ 组合逻辑
01_logic_gates.c可编译
4 变量 Quine-McCluskey 化简器：最小项 + 无关项 → 最简与或式， 打印 16 项真值表、卡诺图、化简前后的门数 / 门输入脚数 / 延迟级数对照， 并验证两级与非（NAND-NAND）等价性。附带 74HC00 环形振荡器频率估算。
学习重点：多数器必须化简成 AB+AC+BC（自查答案）； g 段用了无关项是 A+B'C+BC'+CD'（9 门）， 不敢用 X 就退化成 A'B'C+A'BC'+AB'C'+A'CD'（15 门）； 振荡器 N=3/5/7/9 → 20.83 / 12.50 / 8.93 / 6.94 MHz。
FILE 03 · C17 · ★ 时序逻辑
02_sequential_lab.c可编译
周期精确的边沿触发 D 触发器模型（CLK→Q = 13ns、门 8ns）， 每个时钟沿打印"这个信号在沿后多少 ns 才翻"。 对比异步纹波 / 同步串行使能 / 同步并行进位三种计数器， 外加移位寄存器、异步清空竞争、锁存器 vs 触发器。
学习重点：0111→1000 跳变在 +13/+26/+39/+52 ns，途中冒出 3 个假状态 6 / 4 / 0 各持续 13.0 ns； 并行超前进位是 0 个；16 位纹波 fmax 只剩 4.81 MHz。
FILE 04 · C17 · ★★ 本关最重要
03_setup_hold.c可编译
建立/保持时间实验台：扫描频率打印"能跑 / 临界 / 失败"； MTBF 公式并折算成年、天、毫秒；格雷码转换 + 异步 FIFO 空满自测； 固定种子（srand(20260315)）一百万次蒙特卡洛， 对比 0 / 1 / 2 / 3 级同步器的错误率。
学习重点：场景 A fmax = 89.29 MHz； 场景 C 表面 192.31 MHz 但保持裕量恒为 −0.50 ns， 9 行全废 —— 降频救不了保持违例； MTBF（τ=0.5 / 100MHz）1 级不足 1 ns、2 级 431 ms、3 级 6.63 年。
FILE 05 · C17 · ★ 工程落地
04_fsm_traffic.c可编译
通用表驱动 FSM 引擎（状态枚举 + 事件枚举 + const Rule table[] + default）， 套两个真实场景：十字路口交通灯（行人请求 / 车流传感 / 故障安全态） 与按键消抖（10ms 采样、短按 / 长按 / 连发）。 外加对照组：把 default 删掉，看状态变量怎么跑飞并永久卡死。
学习重点：转移表 23 条（FAULT 显式占 6 条）； 40 拍里 default 命中 1 次、非法状态 0 次 = PASS； 对照组非法状态 4 次 = 永久卡死； 消抖汇总：毛刺作废 1 / 按下 2 / 短按 1 / 长按 1 / 连发 1。

学习顺序建议

顺序不能乱。这一关的门槛不在"逻辑对不对"，在"时间对不对"—— 前两个文件建立"逻辑最简"的直觉，中间两个把"时间"这把刀递到你手里， 最后一个才谈工程组织。跳过 01/02 直接看 03，公式你会背但不会怕。

  1. 先读 tutorial.md 第一、二节。 把"电平是区间不是值"这根弦绷上，再看后面所有东西才不会当成理论课。
  2. 玩 karnaugh_lab.html。 手点 16 格，先在纸上自己圈，再开高亮对答案。这一步建立的是直觉，别跳。
  3. 跑 01_logic_gates.c。 用算法验证你的直觉。重点看"代价对照"两行：门数、门输入脚总数、延迟级数。
  4. 跑 02_sequential_lab.c。 从"逻辑对"跨到"时间对"。盯死 0111→1000 那一拍的 13/26/39/52 ns 和 3 个假状态——这是毛刺第一次以数字的形式出现在你面前。
  5. 拖 setup_hold_animator.html。 先建立画面感：数据在路上跑、时钟在门口等。preset 逐个切，看裕量条怎么变色。
  6. 跑 03_setup_hold.c。 把画面感变成能算的数。场景 C 是本关最重要的一张表， 看懂它你就理解了为什么"全绿的 STA 报告"能骗人。
  7. 跑 04_fsm_traffic.c。 前面所有东西最终要落到"能交付的代码"。这张 const 表 + 一个引擎 + 一个 default， 就是你以后写任何协议栈、任何控制器的骨架。
  8. 回到 tutorial.md 第五、六、七节。 11 条坑逐条对照自己的板子；做完 5 道作业；对着通关清单逐条打勾。 最后拿白纸把五件事从空白重做一遍，才算过。

# 3. 建立/保持时间 + 亚稳态 MTBF + 同步器蒙特卡洛（固定种子，可复现）

.\03_setup_hold.exe

# 4. 表驱动状态机：交通灯 + 按键消抖（纯确定性，无随机数）

# 交互动画：不用编译，双击 HTML 文件即可（完全离线，无 CDN / 无外部字体 / 无 js 依赖）

两个 C 语言细节值得记：① 严格 -std=c17 下 MSYS2 不暴露 M_PI， 要用 π 就自己 #define； ② 03_setup_hold.c 的蒙特卡洛用 srand(20260315) 固定种子—— 换机器、换编译器，只要种子不变，那四个错误率数字一个都不会变。 做实验不固定种子，你对不上账，也骗不了自己。

常见坑速览（课本第五节有全文）

每一条都有人中过招，包括师傅本人。红框 = 会烧东西或量产翻车；黄框 = 会浪费你几天。

CMOS 输入悬空 → 误导通 + 功耗暴涨 74HC 没用到的输入脚留空，内部上下管同时半导通， 静态电流从 200µA 变成 20mA，片子摸着是温的， 电平还随机——盖上机壳一个值、打开机壳另一个值。 所有未用输入必须经 10kΩ 明确接地或接 Vcc。
5V 直连 3.3V MCU → 复位 / latch-up 绝对最大 VDD + 0.3V = 3.6V。5V 从引脚保护二极管倒灌进 3.3V 轨， 把整条轨往上顶。"板子跑着跑着复位"十有八九是这个。 5V-tolerant 要在 datasheet 那一栏查到原话才算，"看着像"不算。
上拉选 100Ω 把驱动门灌爆 (5 − 0.44) / 100 = 45.6 mA，超出 IOL 规范， VOL 被抬高到 1V 以上——判 0 门限是 0.8V， 直接把 0 误判成 1，片子发烫。想提速应该减小总线电容，不是硬压电阻。
open-drain / I²C 忘接上拉 现象最迷惑：读出来全是 1，或者飘忽不定； 有时看着能通（寄生电容存了点电荷），动一下排线就不通。 上电先量 SCL/SDA 是不是高电平——30 秒省你两小时。
只加 100nF 消抖，结果抖 15ms 打穿 RC 算出来 τ = 1ms "绰绰有余"， 但按键 datasheet 写的抖动时间是典型值不是上限。 电容刚放完电，触点又弹回去，MCU 读到第二个边沿。 硬件 RC 取 10~20ms + 74HC14 施密特，软件再做 20~30ms 稳定判定。
把 latch 当 flop 用 74HC373 当 74HC74 用，CP 高电平那半周期数据透明直通， 毛刺原样搬到输出。FPGA 里更惨：综合器默默推断出 latch， warning 你没看，板子中概率出错。RTL 里 if 没有 else 触发的 latch warning 要当 error。
状态机漏 default → 跑飞且爬不回来 04 的对照组演示得很清楚：状态一旦进入未编码组合， 后面喂正常输入也一条规则都匹配不上，永久卡死（非法状态 4 次）。 default 必须指向安全态，不是指向"什么都不做"。
两级同步器被综合器优化掉 代码里写了两级，综合器觉得"这就是根线"， 合并或者 retiming 把两个 FF 拆到十万八千里—— 亚稳态传播的红利用直接归零。 必须加 ASYNC_REG / dont_touch 约束，并在布局报告里核对它们真的挨着。
保持裕量为负还猛降频 保持裕量 = Tco + Tpd(min) − Th − skew， 公式里根本没有 Tclk。数据来得太早就赖在收端门口， 你把时钟放慢它只会来得更早。这是布局问题，不是频率问题。
复位一释放就狂发初始化 电源轨还在爬坡、外设半上电把 SDA 拉住，初始化全部 NACK， 失败状态还被写进标志位，之后再也不重试。 复位后延时 10~50ms，或用 power-good 做硬件门控，并且必须有重试与降级。
按 datasheet 典型值算裕量 典型值 = 一半的片子比它慢，你没算那一半。 74HC 的 tpd 随温度 / 电压 / 负载在 6~15ns 之间漂，同一片不同门也不同。 裕量至少留 20%~30%，并且按 worst case 那一栏算。
化简出"最简"就上，不管毛刺 最简 SOP 是面积最优，不是时序最优。 输入切换瞬间可能出现"两个与门同时为 0"的空窗，输出打一个反毛刺。 关键路径打一拍寄存器同步化，或加冗余项（consensus term）。
